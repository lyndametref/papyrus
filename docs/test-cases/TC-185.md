# TC-185 Deliberate behavior changes are expected deltas and never equivalence failures

## Description
## Scenario: Deliberate behavior changes are expected deltas and never equivalence failures

GIVEN the recorded expected deltas for the uniform title command surface, the removal of the term option, help prose, asset headers, and latency
WHEN the equivalence gate reports a difference in one of those areas
THEN the difference is attributed to its expected delta and does not fail the gate
  AND any difference outside the expected delta list fails the gate
  AND the gate output names the delta or the unlisted difference
