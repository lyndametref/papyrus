# TC-136 The nfr family uses dotted IDs and exposes no nfreq alias

## Description
## Scenario: The nfr family uses dotted IDs and exposes no nfreq alias

GIVEN a project whose configuration enables the grouped type nfr
WHEN a contributor creates an nfr group titled Performance and a member titled Latency
  AND invokes the former nfreq command
THEN the group has a plain ID of the form NFR-nnn and the member a dotted ID of the form NFR-nnn.001
  AND the member's group key names the nfr group
  AND the nfreq invocation is a usage error with exit code 2
