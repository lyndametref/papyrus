# NFR-003.001 Rust Implementation

## Description

The Papyrus application shall be implemented in Rust.

## Rationale

A single compiled Rust core library, statically linked into both front-end binaries, keeps runtime dependencies minimal.

## Verification Method

Inspect the source tree under apps/ and the workspace manifests to confirm that the application is implemented in Rust and built with Cargo.
