# NFR-007.001 Inventory latency at 1,000 records (p95 under 250 ms)

## Group
NFR-007 07 Document Engine Performance

## Description
The document-type inventory page (/) must render within a p95 of 250 ms with 1,000 active records across all document types on the reference hardware.

Reference hardware: 4 vCPU, 8 GiB RAM, SSD, Linux, release build with LTO and strip, single server process, loopback HTTP.
Measurement method: the MS-032 benchmark harness generates 1,000 records, warms up with 10 requests, then measures 100 sequential requests and reports p50 and p95 server-observed latency plus total wall time; the harness command and dataset are recorded with the result.
Condition: the corpus contains at least one GroupedMarkdown type with 200 members and one SingleHtmlMockup type with 50 records.
