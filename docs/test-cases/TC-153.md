# TC-153 A new mockup starts draft and stores its metadata in the HTML comment

## Description
## Scenario: A new mockup starts draft and stores its metadata in the HTML comment

GIVEN a project whose configuration enables the ui-mockup type
WHEN a contributor creates a mockup with a title and references to a task and a specification
THEN the mockup's metadata state is draft
  AND the HTML metadata comment records the status and the references
  AND the HTML file carries no YAML front matter
