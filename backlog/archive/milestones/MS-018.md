## Description

Deliver REQ-07.001–REQ-07.004, REQ-06.014, and the REQ-01.002 list-valued key support: three artifact categories, a runtime artifact registry and per-type descriptors, `document_types` keyed by CLI command slug with fail-closed validation and repair mode, registry-derived CLI dispatch and browser views, the generic document content model, document main/custom statuses with archive-only relocation, and the removal of the static document commands and `nfreq`.

Architecture: ADR-0016 (runtime dispatch), ADR-0017 (registry/descriptors), ADR-0018 (generic content model), ADR-0019 (fail-closed validation), ADR-0020 (registry-derived browser), ADR-0022 (document lifecycle), ADR-0023 (consolidated layout/field map), ADR-0024 (list-valued config keys).

Out of scope: man-page generation and inventory for config-defined slugs. ADR-0021 is Proposed and deferred by the owner; NFR-03.003 is recorded as a release risk. The milestone is a single coherent increment after Release 1.0; no release gate is created here.
