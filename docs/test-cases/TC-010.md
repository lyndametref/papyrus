# TC-010 HTTPS Origin scheme is normalized and accepted

## Description
## Scenario: HTTPS Origin scheme is normalized and accepted

GIVEN an initialized Papyrus project with at least one editable record
  AND the browser server running on `127.0.0.1:<port>`
  AND a valid urlencoded edit form body for that record, including its current `version` token
WHEN a POST is sent with an `Origin` using the `https://` scheme
THEN the POST returns `303 See Other` (not `403`)
  AND the edit is persisted
