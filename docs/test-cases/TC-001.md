## Scenario
Run `papyrus import backlog --from <source>` on a Backlog.md task whose `assignee` list contains an entry beginning with `@` (for example `- @rust-dev`) and inspect the imported Papyrus task file.

## Preconditions
- A source Backlog.md project containing a task file with an unquoted assignee entry `- @rust-dev`.
- An initialized Papyrus target project with no existing task records (or `--allow-existing`).

## Steps
1. Create the source Backlog.md task file with `assignee:\n  - @rust-dev`.
2. Run `papyrus import backlog --from <source>`.
3. Read the imported task file (for example `backlog/tasks/TASK-001.md`).
4. Run `papyrus task view <imported-id>`.

## Expected outcome
- The imported file's `assignee` block uses Papyrus-canonical YAML quoting, for example `assignee:\n  - '@rust-dev'`.
- The front matter parses as valid YAML and `papyrus task view` reports `assignee: @rust-dev`.
- No metadata is lost because of an unquoted `@` token.
