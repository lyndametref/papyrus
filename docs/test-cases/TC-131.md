# TC-131 A created record carries the general front matter plus exactly its declared fields

## Description
## Scenario: A created record carries the general front matter plus exactly its declared fields

GIVEN a project whose configuration enables the ui-spec type
WHEN a contributor creates a UI specification with a title, a view, and a description
THEN the record's front matter carries id, title, status, labels, references, created_date, and updated_date
  AND it carries no front-matter key for view or description
  AND the body sections appear as View then Description in field sequence order
