# TC-015 Milestone archive closes an open milestone and moves it to the archive folder

## Description
## Scenario: Milestone archive closes an open milestone and moves it to the archive folder

GIVEN an initialized Papyrus project with an open milestone MS-001
WHEN the user runs `papyrus milestone archive MS-001`
THEN the milestone is closed first and its status becomes `closed`
  AND the file is moved to `backlog/archive/milestones/MS-001.md` and the status stays `closed` rather than changing to a separate archived status
  AND `updated_date` is refreshed once
  AND title, description, labels, references, and release assignment are preserved
  AND the command exits 0 and prints the milestone ID
  AND the archived milestone is hidden from active milestone lists
