# TC-100 The status verb rejects archived and names archive as the only way to archive

## Description
## Scenario: The status verb rejects archived and names archive as the only way to archive

GIVEN an active document record
WHEN a contributor runs the document status command for that record with archived
THEN the command reports one validation outcome and exits with code 4
  AND the outcome names archive as the only way to archive a record
  AND the record's status is still active
  AND no file has moved
