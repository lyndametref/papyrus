# TC-109 An absent collection inherits the seed while a present collection replaces it

## Description
## Scenario: An absent collection inherits the seed while a present collection replaces it

GIVEN a configuration entry for glossary that declares no label
  AND declares slots as an empty sequence
  AND declares no fields
WHEN a contributor prints the effective configuration
THEN the effective label is the seed label for glossary
  AND the effective slots are empty rather than the seed slots
  AND the effective fields are the seed fields of glossary
