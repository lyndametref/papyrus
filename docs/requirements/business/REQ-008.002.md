# REQ-008.002 Provide Per-Command Help

## User Story

As a Papyrus user, I want each command to explain itself on demand so that I can use it without leaving the terminal.

## Group

REQ-008 User Documentation

## Criticality

Must have

## Description

Every built-in command and every subcommand accepts `-h` and `--help`. `papyrus --help` prints the top-level help, which lists the built-in commands and every configured record-type command, for document types and decision types alike. A command's help prints its name, description, positional arguments, options, and default values.

**Document-type commands.** A command generated for a configured document type accepts `--help` like any other command and shows the verbs derived from its model, the options generated from its field sequence in sequence order, and the title contract (REQ-007.003). This is the only surface that enumerates a specific type's options.

**Decision-type commands.** A command generated for a configured decision type accepts `--help` like any other command and shows its fixed verbs and fixed options; it has no field-derived options (REQ-007.003).

**Behaviour.** Help output is produced without reading records and without writing anything, and the command exits successfully. Help output for one configuration is identical across runs, machines, working directories, terminal widths, and locales, and contains no absolute path, host name, timestamp, process identifier, or memory address.

## Acceptance Criteria

- Every built-in command and every subcommand accepts `-h` and `--help`.
- `papyrus --help` lists the built-in commands and every configured record-type command, document and decision alike.
- A command's help shows its name, description, positional arguments, options, and default values.
- A document-type command's help shows its model-derived verbs, its field options in field-sequence order, and the title contract.
- A decision-type command's help shows its fixed verbs and fixed options.
- Help output requires no record read and writes nothing, and the command exits successfully.
- Help output is identical across runs, machines, working directories, terminal widths, and locales, and contains no absolute path, host name, timestamp, process identifier, or memory address.
