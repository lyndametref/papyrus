# RE-004 Uniform single-document browser layout for all document types

## Description
Requested UI improvement: for all document types, use the same browser layout for the single-document view. On that layout, replace all cards with:
- id: small above the title (as now)
- title: big bold (no changes needed)
- status: beside id in "label" format, must be able to color in the future
- references (dependencies and dependents): collapsible under the title
- data (created/updated): small, directly under the title, before references
No repetition of the document type on the view. Place these elements under the content of the artifact.
