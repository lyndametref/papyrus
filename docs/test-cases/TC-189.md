# TC-189 Vendor assets are immutable at versioned URLs

## Description
## Scenario: Vendor assets are immutable at versioned URLs

GIVEN a running server built from the refactor
WHEN a contributor requests a vendored asset from its versioned package and asset-version URL
THEN the response has status 200 with public, max-age 31536000, and immutable caching and carries no entity tag
  AND a conditional request for that URL receives the full 200 and never a 304
