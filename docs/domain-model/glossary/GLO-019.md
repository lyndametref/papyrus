# GLO-019 Record Model

## Definition
A model that defines a record type's body format, field storage, identifier shape, and state representation. The configured record models are `simple-record`, `grouped-record`, and `formatted-record`; the old values SingleMarkdown, GroupedMarkdown, and SingleHtmlMockup are former names only.

Related terms: Simple Record, Grouped Record, Formatted Record, Record Type, Document Type.
