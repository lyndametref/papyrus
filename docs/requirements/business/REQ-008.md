# REQ-008 User Documentation

## User Story

As a Papyrus user, I want complete documentation on my machine and in the terminal so that I can use the tool without reading its source.

## Group

REQ-008 User Documentation

## Criticality

Must have

## Description

This group covers the documentation Papyrus provides to its users: the installed manual pages (REQ-008.001), per-command help (REQ-008.002), and the help command (REQ-008.003). The manual is the single source of the text, and the packaging constraint for installing it belongs to NFR-003.003.
