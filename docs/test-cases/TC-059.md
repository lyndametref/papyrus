# TC-059 CLI list and view output keep references for generic document types

## Description
## Scenario: CLI list and view output keep references for generic document types

GIVEN a config-defined document type record that carries references
WHEN the user lists that document type in the CLI
  AND the user views the record in the CLI
THEN the list entry shows the record references
  AND the record view shows the record references
