# TC-061 Typed artifact family list rows omit the reference list

## Description
## Scenario: Typed artifact family list rows omit the reference list

GIVEN tasks, decisions, milestones, releases, requirements, NFRs, audit records, and business rules that carry references
WHEN a reviewer opens each of those family list views
THEN no row shows a reference list
  AND every row still shows the record title and its labels in the title cell
  AND the references of each record appear only in that record's single-record view
