# TC-195 The board shows exactly the configured status columns and no unconfigured-status column

## Description
## Scenario: The board shows exactly the configured status columns and no unconfigured-status column

GIVEN a project whose configured task statuses are ToDo, In-Progress, and Done
  AND a task whose stored status is Blocked, which is not configured
WHEN a contributor opens the Backlog view
THEN the board shows exactly the ToDo, In-Progress, and Done columns in configured order
  AND no extra column is shown for the unconfigured status
  AND the Blocked task is not rendered on the board
  AND the Blocked task still appears in `papyrus task list` and in its record view
