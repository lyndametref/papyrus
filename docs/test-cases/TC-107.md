# TC-107 An empty fields sequence declares a type with no field option

## Description
## Scenario: An empty fields sequence declares a type with no field option

GIVEN a user-defined type whose configuration declares fields as an empty sequence
WHEN a contributor creates a record of that type with only a title
THEN the create succeeds and the record carries only the general front matter
  AND the create command offers no field option
  AND the record body has no field section
