# NFR-007.002 View and edit latency at 1,000 records (p95 under 100 ms)

## Group
NFR-007 07 Document Engine Performance

## Description
Viewing and editing a document record must render within a p95 of 100 ms with 1,000 active records, measured on the same reference hardware and with the same generated corpus as NFR-07.001.

Measurement method: the benchmark harness measures GET on a document view route and GET on the corresponding edit route for 100 sequential requests after 10 warm-up requests, per document model, and reports p50 and p95. A record with an unresolved reference and a member record in a 200-member group are both included.
Excluded: first request after a cold start and requests that trigger a config reload.
