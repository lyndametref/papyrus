## Scenario: Milestone archive preserves release assignment

GIVEN an initialized Papyrus project with an open milestone MS-009 assigned to release REL-001
WHEN the user runs `papyrus milestone archive MS-009`
THEN the milestone's release assignment is preserved
  AND no release file is modified
  AND the milestone becomes archived
