## Scenario
After the correction, run the task listing commands and confirm that tasks produced by an import with unquoted `@`-prefixed assignee entries (for example TASK-144 and TASK-145) are included both in the unfiltered list and in the milestone-filtered list.

## Preconditions
- Corrected task files exist under `backlog/tasks/` (for example TASK-144 and TASK-145).

## Steps
1. Run `papyrus task list`.
2. Run `papyrus task list --milestone <milestone-id>` using the milestone the imported tasks belong to.

## Expected outcome
- Both commands list the affected tasks (for example TASK-144 and TASK-145).
- The milestone-filtered command returns at least those tasks (not an empty result).
- Each listed entry retains its parsed title and `assignee` value.
