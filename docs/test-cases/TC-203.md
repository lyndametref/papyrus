# TC-203 Decision view and list show the decision fields and exclude archived records

## Description
## Scenario: Decision view and list show the decision fields and exclude archived records

GIVEN decisions of one type in `proposed` and `superseded` states and one archived decision
WHEN the user runs `papyrus <slug> view <ID>` for each decision
  AND the user runs `papyrus <slug> list`
THEN the view shows the identifier, title, type, status, decision text, context, consequences, dates, labels, and references
  AND the superseded decision's view names its successor
  AND the archived decision is viewable with its stored status
  AND the list shows the non-archived decisions and excludes the archived one
