# TC-014 Non-POST requests ignore Origin

## Description
## Scenario: Non-POST requests ignore Origin

GIVEN an initialized Papyrus project with at least one readable record
  AND the browser server running on `127.0.0.1:<port>`
WHEN a `GET` or `HEAD` is sent with a cross-origin or `null` `Origin`
THEN both requests return `200 OK` with the record view (not `403`)
