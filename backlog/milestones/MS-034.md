## Description
Internal checkpoint of one deliverable: document command surface only.

Goal: one field-driven document handler replaces the nine per-type modules and the transitional per-type command tables, per ADR-A, ADR-0016, ADR-0019, ADR-0021, and ADR-042. The eight document ops builders and the document TypedHandler variants remain until MS-035 deletes them with the browser branches (TASK-266/TASK-269). Backlog and decision commands are untouched.

Acceptance criteria:
AC-1 Baseline verbs (create, list, view, edit, status, archive, delete) behave identically for every document type; create-group and --group exist only for GroupedMarkdown; supersede exists only for SingleHtmlMockup; no status verb for SingleHtmlMockup.
AC-2 Uniform title contract: first positional TITLE plus --title on create and create-group, --title on edit, title required on create, non-empty, always present, never clearable on edit, reserved as a field key, --term removed for glossary, audit and create-group gain a positional title additively, HTML mockup metadata uses the same contract.
AC-3 Config commands support field selector paths such as document_types.<slug>.member.fields[story].heading; numeric [0] is accepted; config list prints effective values with key selectors; config get/list resolve field leaves while config set/unset reject fields/group.fields/member.fields edits as file-edit-only; fields is never comma-set; only statuses keeps comma syntax, and api_aliases and slots are declarative file data; unset of a collection resets to seed.
AC-4 The nine typed document modules (test_case, test_report, use_case, ui_spec, glossary, tech_spec, requirement, rule, audit) are deleted; ui_mockup remains as the SingleHtmlMockup surface; the eight document ops builders (generic_document_ops, requirement_ops, glossary_ops, ui_spec_ops, business_rule_ops, audit_ops, tech_spec_ops, use_case_ops) and the document TypedHandler variants remain until MS-035 removes them with the browser branches (TASK-266/TASK-269); task/milestone/release/decision builders remain; backlog and decision modules are unchanged.
AC-5 CLI help goldens are regenerated; every difference from the MS-032 snapshot is attributable to the documented title, option, and derived-verb changes.
AC-6 Requirement-derived field options, create-group, --group, and supersede appear exactly where the DocumentModel allows.
AC-7 Equivalence tests replay the MS-032 CLI fixtures; record files and exit codes match except for recorded title and config-driven differences.
AC-8 Internal checkpoint: milestone verification builds a discarded verification artifact only; no RC version is determined and no package is retained; packaging is waived in line with MS-032 and MS-033 verification (AUD-138, AUD-140) and MS-037's single-release rule.
