# TC-196 Ctrl-C in the full-screen selector exits 1 and restores the terminal

## Description
## Scenario: Ctrl-C in the full-screen selector exits 1 and restores the terminal

GIVEN the init walkthrough is in the full-screen selector phase
  AND the project directory has no `papyrus.config.yml` yet
WHEN the user presses Ctrl-C (`0x03`)
THEN the guard restores the cursor, the alternate screen, and the terminal mode
  AND the process exits with code 1
  AND the message is `interrupted`
  AND no configuration file is written and no directory is created
