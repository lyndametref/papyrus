# TC-113 A mockup entry that declares statuses or default status is rejected

## Description
## Scenario: A mockup entry that declares statuses or default status is rejected

GIVEN the ui-mockup entry declares the statuses pending, approved, and archived
  AND declares approved as its default status
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names document_types.ui-mockup.statuses and document_types.ui-mockup.default_status
  AND the mockup states remain pending, approved, and archived in its HTML metadata
