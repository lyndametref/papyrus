# TC-004 Task list and milestone filter include tasks with @-prefixed assignees

## Description
## Scenario: Task list and milestone filter include tasks with @-prefixed assignees

GIVEN task files exist under `backlog/tasks/` with `@`-prefixed assignee entries in their front matter (for example TASK-144 and TASK-145)
  AND one of the tasks is assigned to a milestone
WHEN the user runs `papyrus task list`
  AND runs `papyrus task list --milestone <milestone-id>` for that milestone
THEN both commands list the affected tasks
  AND the milestone-filtered command returns at least those tasks (not an empty result)
  AND each listed entry retains its parsed title and `assignee` value
