# TC-153 A new mockup starts pending and stores its metadata in the HTML comment

## Description
## Scenario: A new mockup starts pending and stores its metadata in the HTML comment

GIVEN a project whose configuration enables the ui-mockup type
WHEN a contributor creates a mockup with a title, a task ID, and one specification reference
THEN the mockup metadata state is pending
  AND the HTML metadata comment records the task, the specification, and the references
  AND the HTML file carries no YAML front matter
