# TC-062 UI mockup family list rows omit the reference list

## Description
## Scenario: UI mockup family list rows omit the reference list

GIVEN UI mockups that carry references
WHEN a reviewer opens the UI Mockups list view
THEN no row shows a reference list
  AND every row still shows the mockup title and its labels in the title cell
  AND the references of each mockup appear only in its single-record view
