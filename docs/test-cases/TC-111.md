# TC-111 A statuses list that omits active or archived is rejected

## Description
## Scenario: A statuses list that omits active or archived is rejected

GIVEN a user-defined type whose statuses list declares active and draft but not archived
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names document_types.deploy.statuses and states that archived is required
  AND the type has no command
