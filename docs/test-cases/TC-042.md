# TC-042 Decision create stores a multiline decision supplied on standard input

## Description
## Scenario: Decision create stores a multiline decision supplied on standard input

GIVEN a Papyrus project that supports the adr decision type
  AND standard input carries a decision text of three lines
WHEN the user runs the decision create command with the title "Adopt multiline input" and the decision supplied on standard input
THEN the command exits successfully and prints the new decision ID
  AND viewing the decision shows the three decision lines in order, each on its own line
