# TC-160 An existing record without front matter is adopted on first read and only once

## Description
## Scenario: An existing record without front matter is adopted on first read and only once

GIVEN a legacy glossary file with a title heading and a Definition section but no front-matter block
WHEN a contributor views that record
  AND views it again
THEN the first view writes a front-matter block carrying the ID, title, status, labels, references, and both dates
  AND the body content is unchanged
  AND the second view leaves the file unchanged
