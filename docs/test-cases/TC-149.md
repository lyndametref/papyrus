# TC-149 Archiving a record discards its previous custom status value

## Description
## Scenario: Archiving a record discards its previous custom status value

GIVEN a glossary record whose status is review
WHEN a contributor archives that record
THEN the record's status is archived
  AND no front-matter key or metadata value retains review
  AND the record is in the archived subfolder
