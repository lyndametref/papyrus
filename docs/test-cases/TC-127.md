# TC-127 An empty title on edit is rejected and nothing is written

## Description
## Scenario: An empty title on edit is rejected and nothing is written

GIVEN an existing use-case record titled Checkout returns
WHEN a contributor edits that record with an empty title option
THEN the edit reports one validation outcome and exit code 4
  AND the record title is still Checkout returns
  AND the record's updated_date is unchanged
