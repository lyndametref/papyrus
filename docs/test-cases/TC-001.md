# TC-001 Import Backlog.md task with @-prefixed assignee writes Papyrus-canonical quoted entries

## Description
## Scenario: Import Backlog.md task with @-prefixed assignee writes Papyrus-canonical quoted entries

GIVEN a source Backlog.md project containing a task file with an unquoted assignee entry `- @rust-dev`
  AND an initialized Papyrus target project with no existing task records (or `--allow-existing`)
WHEN the user runs `papyrus import backlog --from <source>`
THEN the imported task file's `assignee` block uses Papyrus-canonical YAML quoting (for example `assignee:\n  - '@rust-dev'`)
  AND the front matter parses as valid YAML
  AND `papyrus task view <imported-id>` reports `assignee: @rust-dev`
  AND no metadata is lost because of an unquoted `@` token
