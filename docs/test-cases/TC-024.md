## Scenario: Uniform single-record layout shows metadata in the required order

GIVEN a task record with a title, status, created and updated dates, references, dependencies, and dependents
  AND the record has artifact content
WHEN the user opens the record's single view
THEN the record ID is shown as small text above the title
  AND the title is shown big and bold
  AND the status is shown beside the ID in a label element
  AND the created and updated dates are shown as small text directly under the title and before references
  AND references, dependencies, and dependents are shown as separate collapsible sections under the title
  AND the document type is not shown anywhere on the view
  AND all metadata elements are shown under the artifact content
