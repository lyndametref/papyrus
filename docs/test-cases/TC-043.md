# TC-043 Decision edit stores a multiline context supplied on standard input

## Description
## Scenario: Decision edit stores a multiline context supplied on standard input

GIVEN an existing decision record whose context is "Initial context"
  AND standard input carries a context text of two lines
WHEN the user runs the decision edit command for that record with the context supplied on standard input
THEN the command exits successfully
  AND viewing the decision shows both context lines in order
  AND the decision text and consequences are unchanged
