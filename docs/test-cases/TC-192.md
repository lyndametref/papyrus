# TC-192 An unknown or unconfigured document address returns the not-found page and an archived record is viewable

## Description
## Scenario: An unknown or unconfigured document address returns the not-found page and an archived record is viewable

GIVEN an archived document record, an unknown document ID, and a type that is not configured
WHEN a contributor requests each of those records in the browser
THEN the unknown and unconfigured requests return status 404 and render the shared not-found page
  AND the archived record request returns status 200 and renders the record view
