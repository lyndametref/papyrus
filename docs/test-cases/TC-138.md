# TC-138 A glossary term is the record title and the definition is its required field

## Description
## Scenario: A glossary term is the record title and the definition is its required field

GIVEN a project whose configuration enables the glossary type
WHEN a contributor creates a glossary term with the positional title Cache and the definition A store of reusable results
THEN the record title is Cache
  AND the front matter carries status active and no term key
  AND the body holds the definition under the Definition section
  AND the record ID has the GLO prefix
