# TC-120 A GroupedMarkdown type offers create-group and requires the group on create

## Description
## Scenario: A GroupedMarkdown type offers create-group and requires the group on create

GIVEN a project whose configuration enables the grouped type req
WHEN a contributor requests help for the req command
  AND runs req create with a title but without a group
THEN the verb listing contains create-group and the status verb
  AND the member create is rejected with one validation outcome and exit code 4
  AND the outcome names the missing group
  AND no file is written
