# TC-193 Adoption leaves HTML files and unmanaged prose unchanged

## Description
## Scenario: Adoption leaves HTML files and unmanaged prose unchanged

GIVEN a UI mockup HTML file without front matter
  AND a README file and a prose file under the specifications directory
WHEN a contributor reads the mockup and the prose files through Papyrus
THEN the mockup keeps its HTML metadata and gains no front-matter block
  AND the README and prose files are byte-identical to before
