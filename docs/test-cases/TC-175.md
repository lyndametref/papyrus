# TC-175 check reports configuration findings and runs the checks that need no type set

## Description
## Scenario: check reports configuration findings and runs the checks that need no type set

GIVEN a configuration whose deploy entry declares the unknown field key owner
  AND a task record whose front-matter dependencies disagree with its retained Dependencies section
  AND a file under a deprecated subfolder
WHEN a contributor runs check
THEN the report includes a configuration finding naming document_types.deploy.fields[owner].key
  AND it includes the task front-matter conflict with both values
  AND it names the document checks skipped because the type set is invalid
  AND it reports no finding for the file under the deprecated subfolder
