# TC-144 Rule requirement references are added and removed through the repeatable option

## Description
## Scenario: Rule requirement references are added and removed through the repeatable option

GIVEN a rule that references REQ-001 and REQ-002 through its requirement field
WHEN a contributor edits the rule supplying a requirement value REQ-003 as an additional occurrence
  AND edits the rule again clearing the requirement field and re-supplying REQ-002 and REQ-003
THEN the Requirements section first lists REQ-001, REQ-002, and REQ-003 as separate items
  AND it then lists REQ-002 and REQ-003
  AND a rule may also be created with no requirement reference
