# TC-004 Task list and milestone filter include tasks imported with corrected @assignee entries

## Description
## Scenario: Task list and milestone filter include tasks imported with corrected @assignee entries

GIVEN corrected task files exist under `backlog/tasks/` (for example TASK-144 and TASK-145)
WHEN the user runs `papyrus task list`
  AND runs `papyrus task list --milestone <milestone-id>` using the milestone the imported tasks belong to
THEN both commands list the affected tasks
  AND the milestone-filtered command returns at least those tasks (not an empty result)
  AND each listed entry retains its parsed title and `assignee` value
