# RE-010 Descriptor-driven document engine refactor: fixed owner decisions

## Description
## Request

Create a durable, citable record of the project owner's decisions for the descriptor-driven document engine refactor, so the ADR and requirement rewrites that follow have one accepted source instead of conversation history.

The owner has bought in to every decision below. Each is accepted exactly as written, is fixed for this work, and is not reopenable: neither the implementation nor the ADR or requirement rewrite may revise, soften, split, or reopen a decision. Wording is preserved verbatim from the owner's decision list.

## Owner decisions (14 of 14; accepted, not reopenable)

| # | Decision (verbatim) | Status |
|---|---|---|
| D1 | Supersede ADR-0018 in full, not only decisions 9-10, and replace ADR-0017's descriptor decisions (1-4, 7, 9, 10) with a new model ADR. | accepted, not reopenable |
| D2 | One deliverable only; no intermediate release; internally staged into milestones. | accepted, not reopenable |
| D3 | No new Rust crates; keep clap, serde, serde_json, yaml_serde. | accepted, not reopenable |
| D4 | Backlog (task/milestone/release) and decision records stay bespoke; only documents are unified. | accepted, not reopenable |
| D5 | DocumentModel enum: SingleMarkdown, GroupedMarkdown, SingleHtmlMockup; DocumentModel supersedes ContentModel. | accepted, not reopenable |
| D6 | GroupedMarkdown and SingleHtmlMockup are seed-only; only req/nfr are grouped; only ui-mockup is HTML; user-defined types default to SingleMarkdown. | accepted, not reopenable |
| D7 | Group membership is immutable after creation; preserve required existing active group of the same type, cross-type rejection, archived-group rejection, no cascade on archive/delete, merged list ordering. | accepted, not reopenable |
| D8 | Reference visibility is seed data per type/role; ADR-0035 is amended. | accepted, not reopenable |
| D9 | Equivalence gate: record files, JSON, and status codes strict; rendered HTML semantic. | accepted, not reopenable |
| D10 | Presentation facts live in the config seed. | accepted, not reopenable |
| D11 | Keep the mtime config/registry cache. | accepted, not reopenable |
| D12 | Asset caching: versioned immutable vendor files; app.css/app.js no-cache with ETag/304; assets only; HTML/JSON stay no-store. | accepted, not reopenable |
| D13 | Title is fixed and non-configurable; single-line, non-empty, always present, required on create, never clearable on edit; not a field; reserved field key; uniform CLI positional title plus --title on create/create-group and --title on edit; --term removed; audit and create-group gain a positional title additively; HTML mockup metadata uses the same contract. | accepted, not reopenable |
| D14 | Config format: nested group/member blocks; fields is a YAML sequence; no per-field order or enabled; scalars fill from seed; collections replace; model/title/content/id_shape are not config keys; init writes a minimal file; config list is full and uses selector paths; adding a field is file-edit-only. | accepted, not reopenable |

## Target architecture

- Three category handlers: Backlog, Decision, Document.
- One schema-driven document engine with three models (`DocumentModel`): `SingleMarkdown`, `GroupedMarkdown`, `SingleHtmlMockup`.

## Scope

- This request artifact and the fourteen owner decisions above.
- The target architecture statement: three category handlers (Backlog, Decision, Document) and one schema-driven document engine with `DocumentModel` = `SingleMarkdown`, `GroupedMarkdown`, `SingleHtmlMockup`.

## Out of scope

- Any requirement change (REQ and NFR records).
- Any ADR change.
- Any TECH (technical specification) change.
- Any code change.

## Affected artifacts

- REQ-007.004 — generic content model for config-defined document types; its `ContentModel` basis is superseded by `DocumentModel` (D5).
- ADR-0017 — three-category registry and type descriptors; descriptor decisions 1-4, 7, 9, and 10 are replaced by a new model ADR (D1).
- ADR-0018 — generic document content model; superseded in full (D1).
- ADR-0035 — per-family reference visibility; amended so reference visibility is seed data per type and role (D8). The record carries the id `ADR-035`.

## Open questions

None. All fourteen decisions are fixed and accepted; nothing in this request is pending.
