# TC-170 The document list status filter offers active plus the configured custom statuses

## Description
## Scenario: The document list status filter offers active plus the configured custom statuses

GIVEN a document type whose declared statuses are review and final
  AND records in the statuses active, review, and final
WHEN a contributor opens the type's list and selects review
  AND submits a filter value outside the offered set
THEN the filter options are active, review, and final in that order with no archived option
  AND the list shows only the records whose status is review
  AND the unknown filter value is rejected rather than applied
