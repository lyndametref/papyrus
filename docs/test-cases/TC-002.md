## Scenario
Import a Backlog.md task that carries status, milestone, labels, dependencies, documentation, type, and ordinal metadata, then verify that the imported Papyrus task retains all of those values (with references translated where applicable).

## Preconditions
- A source Backlog.md project containing a task with populated status, milestone, labels, dependencies, documentation, type, and ordinal fields.
- An initialized Papyrus target project containing the referenced milestone and dependency tasks after import ordering.

## Steps
1. Run `papyrus import backlog --from <source>`.
2. Read the imported task file.
3. Run `papyrus task view <imported-id>` and `papyrus task list`.

## Expected outcome
- `status`, `labels`, `documentation`, `type`, and `ordinal` match the source values.
- The milestone reference is translated to the imported milestone ID (or dropped to `null` when unresolved).
- Each dependency is translated to the imported task ID (or dropped when unresolved).
- `papyrus task list` shows the imported task with its title rather than the ID fallback.
