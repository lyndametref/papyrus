# TC-108 A grouped entry that declares a top-level fields sequence is rejected

## Description
## Scenario: A grouped entry that declares a top-level fields sequence is rejected

GIVEN an entry for the grouped type req that declares fields at the top level beside its group and member blocks
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names document_types.req.fields
  AND no document-type set is used
