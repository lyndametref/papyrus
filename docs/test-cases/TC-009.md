## Scenario: IPv6 Origin is normalized and accepted

GIVEN an initialized Papyrus project with at least one editable record
  AND the browser server running on `[::1]:<port>` (or `127.0.0.1:<port>` with `::1` in the allowed host set)
  AND a valid urlencoded edit form body for that record, including its current `version` token
WHEN a POST is sent with an `Origin` containing an IPv6 host in bracketed and unbracketed forms
THEN both POSTs return `303 See Other` (not `403`)
  AND IPv6 brackets do not cause a mismatch
