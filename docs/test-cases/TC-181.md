# TC-181 HTML and JSON responses are never cacheable and no response is compressed

## Description
## Scenario: HTML and JSON responses are never cacheable and no response is compressed

GIVEN a running server built from the refactor
WHEN a contributor requests an HTML page, a JSON response, an error response, and a not-found response
THEN every response carries no-store caching, no validator, and never a 304
  AND no record-derived response carries a cacheable directive
  AND no response carries a content-encoding or vary header
  AND no accept-encoding negotiation changes the response
