# TC-007 Legitimate same-site POST edit is accepted

## Description
## Scenario: Legitimate same-site POST edit is accepted

GIVEN an initialized Papyrus project with at least one editable record
  AND the browser server running on `127.0.0.1:<port>`
  AND a valid urlencoded edit form body for that record, including its current `version` token
WHEN a browser edit form POST is sent whose `Origin` exactly matches the request URL
THEN the POST returns `303 See Other` (not `403`)
  AND the record view shows the edited values
  AND the underlying record file contains the edited values
