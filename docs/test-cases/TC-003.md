## Scenario
After the quoted-assignee correction, parse task files that an import produced with unquoted `@`-prefixed assignee entries (for example `backlog/tasks/TASK-144.md` and `backlog/tasks/TASK-145.md`) and confirm that their front matter is valid YAML and that Papyrus reads their full metadata.

## Preconditions
- Corrected task files with quoted assignee entries exist under `backlog/tasks/` (for example TASK-144 and TASK-145).

## Steps
1. Run `papyrus task view <imported-id>` for each affected task (for example TASK-144 and TASK-145).
2. Run `papyrus task list`.

## Expected outcome
- Both files parse without falling back to default values.
- `task view` reports `title`, `status`, `assignee`, `milestone`, labels, and dependencies for each task.
- `task list` shows each task's real title rather than its ID.
