# TC-103 An unknown document-type key is rejected with its selector path

## Description
## Scenario: An unknown document-type key is rejected with its selector path

GIVEN a document-type entry that declares the unknown key template
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names the location document_types.req.template
  AND no document command is available
