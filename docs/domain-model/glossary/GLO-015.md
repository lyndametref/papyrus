# GLO-015 SingleMarkdown

## Definition
The document model whose records stand alone, each with a plain identifier, a Markdown body, and one field sequence that may be empty. A record of this model keeps status in front matter.

Also known as: single Markdown model.

Related terms: Document Model, Field Specification, Role.
