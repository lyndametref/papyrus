# UI-017 Papyrus Local Browser (Uniform Single-Document Layout)

## View
uniform-single-document-layout

## Description
Ticket: TASK-165. Uniform single-document browser layout for every managed Markdown record type with a single record view (REQ-06.012, RE-004, ADR-033, TECH-079). Replaces the previous summary-card single record layout (UI-014 section 5). UI mockup HTML views are excluded. Layout (all metadata under artifact content, in order): 1) record ID small above title; 2) title big and bold; 3) status beside the ID in a label element (color deferred, no color now); 4) created and updated dates as small text directly under the title, before references; 5) references, dependencies, and dependents as separate collapsible native details sections under the title, each only when the record has at least one value, collapsed by default, working without JavaScript. The document type is not repeated anywhere on the view. Labels remain as a taglist under the title where already specified. Navigation and interactions: breadcrumb links, Edit button, disclosure summaries, and reference links (task dependencies, milestone, references, owning group) as hyperlinks when they resolve to a Papyrus record; unresolved references render as plain text with no error. Platforms: web only (local browser); desktop frame; responsive behavior inherited from the shared shell (UI-016); no platform-specific layout differences. Active elements: breadcrumb links, Edit button, disclosure summaries, reference links, sidebar toggle at narrow widths. States: collapsed disclosure sections by default; works without JavaScript and in Firefox 115+ (NFR-05.001); all Papyrus content viewable and editable (NFR-01.002). Open questions: status label colors deferred to a future change; scope is all managed Markdown record types with a single record view.
