# TC-034 Routes for removed browser sections are unreachable

## Description
## Scenario: Routes for removed browser sections are unreachable

GIVEN the browser is running for a project
WHEN a user requests the route of a removed section
THEN the browser does not serve that section's page
  AND the response indicates the page is not available
  AND no content of the removed section is displayed
