# TC-028 Single-record view works with JavaScript disabled

## Description
## Scenario: Single-record view works with JavaScript disabled

GIVEN a browser with JavaScript disabled
  AND a record with references, dependencies, and dependents
WHEN the user opens the record's single view
THEN the page renders without errors
  AND the disclosure sections remain usable as native elements
  AND the record content and metadata are visible
