# GLO-014 Document Model

## Definition
The rule that fixes the shape of a document type's records: how many records exist and with which identifiers, which field sets and roles apply, where status is kept, and which verbs the type exposes. There are exactly three document models: SingleMarkdown, GroupedMarkdown, and SingleHtmlMockup.

Also known as: DocumentModel.

Related terms: SingleMarkdown, GroupedMarkdown, SingleHtmlMockup, Document Type.
