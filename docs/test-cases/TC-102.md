# TC-102 A user-defined slug gains a simple-record command with the documented defaults

## Description
## Scenario: A user-defined slug gains a simple-record command with the documented defaults

GIVEN a configuration that adds the document type deploy with only a prefix and a directory
WHEN a contributor lists the available commands
  AND creates a deploy record with a title
THEN the deploy command is available with the verbs of a simple-record type: create, list, view, edit, archive, delete, and status
  AND the new record has a plain identifier under the DEP prefix and the status active
  AND the record's only declared field is an optional multiline description stored under the Description heading
