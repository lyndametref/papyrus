# TC-057 Shared list layout for generic document types is otherwise unchanged

## Description
## Scenario: Shared list layout for generic document types is otherwise unchanged

GIVEN a config-defined document type whose records span several statuses
WHEN a reviewer opens the document type list view
  AND the reviewer applies the status filter
THEN the fixed column order, grouped rows, and View and Edit row actions are unchanged
  AND the filtered list shows only records in the selected status
  AND the page width and shell layout match the shared list contract
