# TC-130 A document-types entry declaring model is valid and unknown keys are ignored with a warning

## Description
## Scenario: A document-types entry declaring model is valid and unknown keys are ignored with a warning

GIVEN a document-type entry for deploy that declares the model simple-record and the keys title, content, and id_shape
WHEN a contributor runs any command in that project
  AND runs check
THEN the declared model is applied as a valid key and the deploy command behaves as a simple-record family
  AND each of title, content, and id_shape is accepted, ignored, and reported as one warning naming its location such as document_types.deploy.title
  AND check reports each ignored key as a finding at the same location
  AND no command is refused and no behavior changes because of the ignored keys
