# TC-116 config unset of a collection restores the seed collection

## Description
## Scenario: config unset of a collection restores the seed collection

GIVEN a glossary entry that overrides its statuses with active, archived, and review
WHEN a contributor unsets document_types.glossary.statuses
THEN the effective statuses of glossary are the seed statuses active and archived
  AND the review status is no longer offered by the glossary command
