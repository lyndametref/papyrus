# GLO-002 Milestone


## Definition
A grouping for tasks that may be assigned to zero or one release. Its lifecycle is fixed as open -> closed; archived is a file position, not a status. `papyrus milestone close` closes it; `papyrus milestone archive` moves its file to `<backlog_dir>/<milestone_dir>/archive` with the status unchanged, and there is no restore (REQ-002.005, REQ-007.001).
