# TC-053 The editor path still edits a multiline description

## Description
## Scenario: The editor path still edits a multiline description

GIVEN an existing request record with a single-line description
  AND an editor that saves a description of three lines
WHEN the user runs the request document edit command for that record in editor mode
THEN the command exits successfully
  AND viewing the record shows the three description lines from the editor in order
