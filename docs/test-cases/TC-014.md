## Scenario
Origin validation applies only to `POST` requests; a `GET` or `HEAD` with a cross-origin or `null` `Origin` is handled normally.

## Preconditions
- An initialized Papyrus project with at least one readable record.
- The browser server running on `127.0.0.1:<port>`.

## Steps
1. Send `GET /doc/<record-id>` with `Host: 127.0.0.1:<port>` and `Origin: http://evil.example:<port>`.
2. Send `GET /doc/<record-id>` with `Host: 127.0.0.1:<port>` and `Origin: null`.

## Expected outcome
- Both requests return `200 OK` with the record view (not `403`).
