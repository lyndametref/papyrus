## Scenario: Removal does not change underlying records or configuration files

GIVEN a project with existing records and configuration
WHEN the browser sections are removed
THEN the underlying record files remain unchanged
  AND the configuration file remains unchanged
  AND record identifiers, prefixes, and folders remain the same
