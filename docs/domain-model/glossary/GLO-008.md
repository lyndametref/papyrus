# GLO-008 Formatted Record

## Definition
A record model whose records have an HTML body, a plain identifier, no field sequence, and status and references in an HTML metadata comment instead of YAML front matter. The metadata keys are exactly `status` and `references`; the record title is the content of the HTML `<title>` element. The states are `draft` and `approved`; a new record starts `draft`; `approved` is reached through `edit --status approved`. Archived is a file position, not a status value: `archive` moves the file into `archive/` and changes no status, and a draft or approved record may be archived. A formatted record cannot be superseded. Papyrus does not version a record.

Also known as: HTML mockup model.

Current model value: `formatted-record`. Former name: SingleHtmlMockup. The term "Formated Recorded" was corrected to "Formatted Record".

Related terms: Document Type, Role, Record Model, Record Type.
