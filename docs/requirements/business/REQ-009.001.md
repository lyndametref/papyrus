# REQ-009.001 Search Project Records

## User Story

As a project contributor, I want to search backlog and documentation records together so that relevant project information is found without searching the stores separately.

## Group

REQ-009 Search

## Criticality

Must have

## Description

`papyrus search <QUERY>` runs one free-text search across every managed record: tasks, milestones, releases, decisions, and every document type declared in the configuration (REQ-007.002). A query matches record values, including record metadata, titles, and body text. A quoted phrase containing spaces is treated as one query.

The search can be restricted with repeatable `--type` options. The documented type values are the built-in types `task`, `milestone`, and `release`, plus the slug of every configured decision type and every configured document type; when no `--type` is given, all types are searched. An unknown type value is rejected with a validation outcome. `--limit <n>` caps the number of results.

Archived records are excluded by default: a document, milestone, release, or decision moved into an archive folder is not returned, and neither is an archived task (REQ-005.007). `--include-archive` adds them to the search, and a returned archived record shows its archived state in the result. Search runs locally and requires no network access.

The output is plain text by default and honours the global `--json` option (REQ-001.004).

## Acceptance Criteria

- A query searches tasks, milestones, releases, decisions, and every configured document type by default.
- A quoted phrase containing spaces is accepted as one query.
- Query matching covers record metadata, titles, and body text.
- Repeatable `--type` options restrict the results to the selected built-in or configured record types, and an unknown type value is rejected.
- With no `--type`, all record types are searched.
- `--limit <n>` caps the number of returned results.
- Archived records of every category are excluded from the results by default.
- `--include-archive` includes archived records of every category in the results.
- A record returned under `--include-archive` shows its archived state in the plain-text and JSON output.
- `--include-archive` combines with `--type` and `--limit`.
- The search requires no network access.
- The output is plain text by default and honours the global `--json` option.
