## Scenario: Task edit replaces the description with multiline text supplied on standard input

GIVEN an existing task whose description is "Original description"
  AND the task has the status "ToDo"
  AND standard input carries a description of two lines
WHEN the user runs the task edit command for that task with the description supplied on standard input
THEN the command exits successfully
  AND viewing the task shows both description lines in order
  AND the task status remains "ToDo"
