# REQ-006.016 Present a Uniform List View Across Artifact Families

## User Story

As a project contributor, I want every artifact list view to use one shared layout so that browsing, scanning, and acting on records is consistent across the project.

## Group

REQ-006 Search and Local Web Interface

## Criticality

Should have

## Description

Every browser list view for every artifact family — tasks, milestones, releases, decisions, and every document type, including audit records and technical specifications — uses a single shared list layout. The shared layout fixes the common header, row and column structure, and the placement of actions; family-specific fields populate designated slots within it rather than introducing a separate layout. No artifact family uses a bespoke list template that diverges from the shared layout. Archived records remain excluded from every list view (REQ-005.007).

Visual specifics — exact columns, spacing, and styling — remain design decisions; a redesign session may refine them, but the single shared layout contract holds. The layout applies to browser list views only and does not change CLI list output.

## Acceptance Criteria

- Every browser list view for every artifact family uses the same shared list layout.
- The header, row and column structure, and action placement are consistent across all artifact families.
- Family-specific content appears in designated slots of the shared layout rather than through a separate list template.
- No artifact family uses a bespoke list view that diverges from the shared layout.
- Archived records are excluded from every list view.
- The shared layout renders and is usable in the supported browsers (NFR-005.001) and requires no network access (NFR-001.003).
