# TC-145 An audit type write stores the body section and the front-matter type key

## Description
## Scenario: An audit type write stores the body section and the front-matter type key

GIVEN a project whose configuration enables the audit type
WHEN a contributor creates an audit record titled Access review with the audit type licence
THEN the front matter carries the key type with the value licence
  AND the body holds the same value under the Audit Type section
  AND viewing the record shows the body value without merging the two locations
