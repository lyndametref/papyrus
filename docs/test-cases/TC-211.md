# TC-211 Man pages are generated from docs/man and installed by the packages

## Description
## Scenario: Man pages are generated from docs/man and installed by the packages

GIVEN the Markdown sources under `docs/man/`
WHEN the packages are built and installed
THEN the pages are generated to roff at build time and installed under the standard man paths
  AND `papyrus(1)` and `papyrus-config(5)` come from the `papyrus` package and `papyrus-browser(1)` from the browser package
  AND every built-in command appears in `papyrus(1)` and the `<slug>` section explains how a slug is configured
  AND no per-type man page is expected
