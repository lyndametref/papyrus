# NFR-007.002 View and Edit Latency at 1,000 Records

## Description

A document view page and its edit page shall each be served with a p95 latency below 100 ms when 1,000 active records exist.

## Rationale

Makes view and edit usable at the 1,000-record scale the engine is designed for.

## Verification Method

Use the corpus, hardware, warm-up, measured-request count, reporting, and exclusions of NFR-007.001. For each document model, send 100 measured requests to a view route and 100 to the corresponding edit route, including one record with an unresolved reference and one member of the 200-member group. p95 for view and for edit shall each be below 100 ms; record the run and the measured figures with the release.
