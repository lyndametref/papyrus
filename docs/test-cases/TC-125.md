# TC-125 A create that supplies both title sources is rejected

## Description
## Scenario: A create that supplies both title sources is rejected

GIVEN a project whose configuration enables the glossary type
WHEN a contributor creates a glossary term with the positional title Cache and the title option Caching
THEN the create reports one validation outcome and exit code 4
  AND the outcome names the conflicting title sources
  AND no glossary record is written
