# TC-139 A glossary invocation that supplies term is a usage error

## Description
## Scenario: A glossary invocation that supplies term is a usage error

GIVEN a project whose configuration enables the glossary type
WHEN a contributor creates a glossary record with the term option and a definition
  AND edits an existing glossary record with the term option
THEN each invocation is a usage error with exit code 2
  AND the outcome names the unknown term option
  AND no glossary record is written or changed
