# TC-116 config unset of a collection restores the model default

## Description
## Scenario: config unset of a collection restores the model default

GIVEN a glossary entry that overrides its statuses with review and draft
WHEN a contributor unsets document_types.glossary.statuses
THEN the glossary entry's statuses fall back to the model-level default of no custom statuses
  AND active is the only workflow status the glossary command offers
  AND the review status is no longer offered by the glossary command
