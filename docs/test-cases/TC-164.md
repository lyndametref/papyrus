# TC-164 CLI, JSON, and browser show a custom status value verbatim

## Description
## Scenario: CLI, JSON, and browser show a custom status value verbatim

GIVEN a glossary record whose stored status is review
WHEN a contributor lists the glossary records in the CLI and in JSON
  AND opens the glossary list and the record view in the browser
THEN every surface shows the status value review
  AND no surface renames it to a display label
