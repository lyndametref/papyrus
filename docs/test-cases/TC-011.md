## Scenario
A POST carrying `Origin: null` (as sent by sandboxed or `file://` contexts) is rejected with `403`, even though the `Host` header is valid.

## Preconditions
- An initialized Papyrus project with at least one editable record.
- The browser server running on `127.0.0.1:<port>`.
- A valid urlencoded edit form body for that record, including its current `version` token.

## Steps
1. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, `Origin: null`, `Content-Type: application/x-www-form-urlencoded`, and the valid form body.

## Expected outcome
- The POST returns `403 Forbidden`.
- No record file is modified.
