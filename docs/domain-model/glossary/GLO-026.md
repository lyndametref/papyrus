# GLO-026 Document

## Definition
A managed record that belongs to the document record category. Its kind is declared by a document type, which fixes its record model, field sequence, prefix, folder, and status model. A document record is one instance of that type; it is not the document type itself.

Related terms: Record, Record Type, Record Category, Document Type.
