# TC-132 A patch that changes nothing performs no write

## Description
## Scenario: A patch that changes nothing performs no write

GIVEN an existing glossary record with a definition and a recorded updated_date
WHEN a contributor edits the record with the same definition value
THEN the command reports success
  AND the record file's bytes are unchanged
  AND the record's updated_date is unchanged
