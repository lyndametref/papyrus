## Scenario
Import a Backlog.md task whose `assignee` field is an empty list (`assignee: []`) and verify that the imported Papyrus task keeps an empty assignee list that parses correctly.

## Preconditions
- A source Backlog.md task with `assignee: []`.
- An initialized Papyrus target project.

## Steps
1. Run `papyrus import backlog --from <source>`.
2. Read the imported task file.
3. Run `papyrus task view <imported-id>`.

## Expected outcome
- The imported file contains `assignee: []`.
- The file parses as valid YAML and `papyrus task view` reports no assignees.
- No spurious unquoted tokens are introduced.
