# REQ-06 Search and Local Web Interface

## User Story
As a project contributor, I want to search project records and use the local web interface so that backlog and documentation information can be discovered in a single project context.

## Description
This group covers unified free-text search across the documented record types, starting the local web UI over the project's backlog and documentation stores, a browser page describing the managed artifact types and their lifecycles, a browser page listing agent skills and workflows for configuring Papyrus via `papyrus.conf.yaml`, and CLI and browser views that render record metadata from front matter.
