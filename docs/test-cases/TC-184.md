# TC-184 Rendered HTML is compared semantically rather than by bytes

## Description
## Scenario: Rendered HTML is compared semantically rather than by bytes

GIVEN the fixture corpus and the captured baseline HTML pages
WHEN the refactored build renders the same list, view, and edit pages
THEN each page matches its baseline on the selected elements, visible text, navigation entries, and form fields
  AND each page contains no per-type wrapper element
  AND differences in attribute order, whitespace, and insignificant markup are ignored
  AND a difference in any compared element, text, link, or field fails the gate
