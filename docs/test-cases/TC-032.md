# TC-032 Reference links resolve when possible and unresolved references render as plain text

## Description
## Scenario: Reference links resolve when possible and unresolved references render as plain text

GIVEN a record whose references, dependencies, and dependents include one value that resolves to a Papyrus record and one that does not
WHEN the user opens the record's single view and expands the relevant section
THEN the resolving value is rendered as a hyperlink
  AND the unresolved value is rendered as plain text without an error
