# TC-210 The three amd64 Debian packages install and smoke-test on Debian Forky

## Description
## Scenario: The three amd64 Debian packages install and smoke-test on Debian Forky

GIVEN the built `papyrus-core`, `papyrus`, and `papyrus-browser` packages at one version
WHEN they are installed on Debian Forky
THEN all three `.deb` files are amd64 at the same version
  AND `papyrus` and `papyrus-browser` declare `Depends: papyrus-core (= <version>)`
  AND the installed binaries run their commands in a smoke test
  AND no package starts a service or performs a network operation
