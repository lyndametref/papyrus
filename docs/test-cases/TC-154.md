# TC-154 A mockup state transition that goes backwards is rejected

## Description
## Scenario: A mockup state transition that goes backwards is rejected

GIVEN an approved mockup
WHEN a contributor attempts to return it to draft
THEN the transition is rejected with one validation outcome and exit code 4
  AND the metadata state remains approved
  AND no file is rewritten
