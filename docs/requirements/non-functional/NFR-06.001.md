# NFR-06.001 License Papyrus Under GPL-3.0-or-later

## Description
Papyrus shall be licensed under GPL-3.0-or-later.

## Rationale
This records the requested project license and its “or later” version grant.

## Verification Method
Review the project's licensing declaration and distributed license notice to confirm that they identify GPL-3.0-or-later.
