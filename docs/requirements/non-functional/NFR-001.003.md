# NFR-001.003 Offline Browser Operation

## Description

The `browser` command and the local browser interface shall operate without an internet connection.

## Rationale

The interface is served locally and must stay usable on isolated machines.

## Verification Method

With external networking disabled and loopback available, invoke the `browser` command, exercise list, view, and edit across artifact families, and confirm that the interface remains usable and that no outbound network request is attempted.
