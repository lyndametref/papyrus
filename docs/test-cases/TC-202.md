# TC-202 Decision status verbs perform exactly one transition and reject invalid ones

## Description
## Scenario: Decision status verbs perform exactly one transition and reject invalid ones

GIVEN a decision of the adr type in each status
WHEN the user runs `accept`, `reject`, `deprecate`, and `supersede` from their required starting statuses
THEN each verb performs exactly its one transition and writes the new status
WHEN a verb is applied from any other status
THEN the command is rejected with a validation outcome and exit code 4
  AND nothing is written
  AND `supersede --by` writes the successor into `superseded_by` only for an `accepted` decision of the same type
