# RE-006 Do not show reference list in document-type browser list views

## Description
Requested UI change: in the browser list view for any document type, do not display the reference list, because it makes rows too long. References remain visible in the single-document view. Product decisions 2026-11-18: references are hidden entirely (not collapsed or expandable) in document-type list views; scope is config-defined document types only (tasks, decisions, milestones, releases, and other families unchanged). Resolved open questions recorded in REQ-06.019.
