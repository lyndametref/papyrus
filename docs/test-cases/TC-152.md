# TC-152 A record marked archived in the active folder is not relocated and stays listed

## Description
## Scenario: A record marked archived in the active folder is not relocated and stays listed

GIVEN a glossary record whose front-matter status reads archived
  AND whose file is still in the type's active folder
WHEN a contributor views that record and lists the type's records
THEN the record is returned and listed with the active records
  AND the file stays in the type's active folder and is not relocated
  AND the record's storage state is not archived because its file is not in the archive subfolder
