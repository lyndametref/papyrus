# NFR-03.002 Distribute Papyrus as a Debian Package

## Description
Papyrus shall be distributed as `.deb` packages for the amd64 architecture on Debian Trixie, Forky, and later Debian releases.

## Rationale
This records the requested Debian package format, architecture, and supported release range.

## Verification Method
Inspect the distribution artifacts to confirm that amd64 `.deb` packages are provided and install and verify them on Debian Trixie, Forky, and each later Debian release claimed as supported.

## Open Questions
The phrase “later Debian releases” does not specify a terminal release boundary or which future releases must be verified.
