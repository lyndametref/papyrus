# GLO-016 Record

## Definition
A single managed unit stored as one record file, belonging to exactly one record type and one record category. A record has an identifier, metadata, and a body; for example a task record, a decision record, or a document record. A record is the instance; a record type is the kind it belongs to.

Related terms: Record Type, Record Category, Document Type, Document, Decision Type.
