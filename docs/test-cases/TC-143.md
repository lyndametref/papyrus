# TC-143 A rule edit that clears a required field is rejected

## Description
## Scenario: A rule edit that clears a required field is rejected

GIVEN an existing rule with a description, a rationale, and an applicability
WHEN a contributor edits the rule with an empty description
THEN the edit reports one validation outcome and exit code 4
  AND the outcome names description as required
  AND the stored description and updated_date are unchanged
