# TC-041 Document edit replaces the description with multiline text supplied on standard input

## Description
## Scenario: Document edit replaces the description with multiline text supplied on standard input

GIVEN an existing request record whose description is "Single line summary"
  AND standard input carries a description of two paragraphs separated by a blank line
WHEN the user runs the request document edit command for that record with the description supplied on standard input
THEN the command exits successfully
  AND viewing the record shows both paragraphs with the blank line preserved between them
  AND the record title and metadata are unchanged
