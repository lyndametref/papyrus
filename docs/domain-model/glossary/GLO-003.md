# GLO-003 Release


## Definition
A grouping for milestones that has the fixed planned -> released lifecycle; `papyrus release close` releases it. `papyrus release archive` closes a still-planned release and moves its file to the backlog archive releases directory with the status unchanged; archiving or deleting a release changes no milestone (REQ-002.006, REQ-007.001).
