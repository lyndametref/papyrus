# UI-019 Browser List Reference Visibility by Document-Type Family

## View
document-type-list-reference-visibility

## Description
Ticket TASK-179 (MS-028). Specifies reference visibility in the shared browser list layout per ADR-035 and REQ-006.019 (source RE-006).

**Scope:** web only (local browser), desktop frame; responsive behaviour inherited from the shared shell (UI-016).

### Rule
- `ContentModel::Generic` families (config-defined document types, e.g. Notes) render **no reference list in any list row**. The reference block is omitted entirely, not collapsed, emptied, or expandable.
- `ContentModel::Typed` families (e.g. Business Rules) and the `ContentModel::HtmlMockup` family (UI Mockups) keep the current reference rendering in the Title cell.
- Labels remain rendered in the Title cell for every family, including generic document types. Only references change.
- All other shared-list properties are unchanged: fixed column order `ID, Title, Status, family slot(s), Created, Updated, Actions`; status filter; row actions View then Edit; grouped rows; page width; no-JavaScript behaviour; no network access (NFR-001.003).
- The single-document view for generic document types keeps its collapsible `References (N)` section (REQ-006.012, ADR-033).
- CLI list and view output, the JSON API, `RecordView`, and front matter are unchanged.

### Views and layout
1. **Generic document type list** (`/?type=note`, example Notes): heading `Notes`, count note, status filter (`Status`, `Apply filter`, `Show all`), shared table. Title cell: record title link, then the label tag line only. No reference line appears between the labels and the next row.
2. **Generic document detail** (`/doc/NOTE-001`): unchanged context. Summary card, labels, body, and the `References (N)` disclosure at the end.
3. **Typed family list** (Business Rules): unchanged. The Title cell keeps its label tag line and its reference line.
4. **HtmlMockup family list** (UI Mockups): unchanged. The Title cell keeps its reference line.

### Active elements
- Sidebar document-type links, including `Notes`.
- Status select, `Apply filter`, `Show all` (list views).
- Record title links; row `View` and `Edit` actions.
- `References (N)` disclosure summary and reference links (generic detail).
- Prototype review navigation (scaffolding, not part of the design).

### States
Happy path only. No variants, alternate states, or error states are designed. Row data, labels, and references are illustrative.

### Approval
MOCK-021 records this design. The user explicitly approved MOCK-021, so this specification is verified.
