# TC-035 Configuration editing is not available in the browser and remains available via the CLI

## Description
## Scenario: Configuration editing is not available in the browser and remains available via the CLI

GIVEN a project whose configuration needs to change
WHEN the user attempts to edit configuration in the browser
  AND the user runs the CLI configuration commands
THEN the browser offers no configuration editing view
  AND the CLI reads and updates the configuration successfully
  AND configuration folder moves are performed by the CLI
