# TC-197 Ctrl-C in a canonical prompt terminates the process by signal

## Description
## Scenario: Ctrl-C in a canonical prompt terminates the process by signal

GIVEN the init walkthrough is in a canonical prefix or folder prompt
WHEN the user presses Ctrl-C
THEN the kernel SIGINT disposition terminates the process
  AND the shell-observed status is 130 as the signal convention, not an application exit code
  AND the terminal state stays canonical
  AND no configuration file is written
