# NFR-004.002 Project-Directory Boundary

## Description

Papyrus shall not read from or write to a path outside the project directory, except during `init`. Every path shall be canonicalized and symbolic links resolved; a path that escapes the canonical project root shall be rejected. The `init` exception permits writing outside the project directory only to create the project directory itself.

## Rationale

Confining all access to the project keeps a run from reading or changing files the user did not select.

## Verification Method

Exercise normal operations and `init` while monitoring filesystem access; confirm that no operation except `init` touches a path outside the project directory, that a symlink cannot escape the canonical project root, and that `init` writes outside the project directory only to create it.
