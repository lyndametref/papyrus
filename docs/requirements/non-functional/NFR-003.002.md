# NFR-003.002 Debian Package Distribution

## Description

Papyrus shall be distributed as `.deb` packages for the amd64 architecture on Debian Forky only.

## Rationale

Forky is the only Debian release verified for these packages; no other release is claimed.

## Verification Method

Inspect the distribution artifacts to confirm that the three amd64 `.deb` packages are provided (papyrus-core, papyrus, papyrus-browser), then install them on Debian Forky and smoke-test the installed commands.
