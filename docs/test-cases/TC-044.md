# TC-044 Decision edit stores multiline consequences supplied on standard input

## Description
## Scenario: Decision edit stores multiline consequences supplied on standard input

GIVEN an existing decision record whose consequences are "No known consequences"
  AND standard input carries a consequences text of two lines
WHEN the user runs the decision edit command for that record with the consequences supplied on standard input
THEN the command exits successfully
  AND viewing the decision shows both consequences lines in order
  AND the decision text and context are unchanged
