# TC-056 A newly configured document type list omits the reference list

## Description
## Scenario: A newly configured document type list omits the reference list

GIVEN a project where the config-defined document type Recipes is added after the change
  AND a Recipes record that carries references and labels
WHEN a reviewer opens the Recipes list view
THEN no row shows a reference list
  AND the row still shows the recipe title and its labels
  AND no per-type presentation configuration is added for the new document type
