# TC-052 A single-line description argument is unchanged and does not read standard input

## Description
## Scenario: A single-line description argument is unchanged and does not read standard input

GIVEN standard input is a terminal and carries no piped text
WHEN the user runs the request document create command with the title "Single line request" and a single-line description argument
THEN the command completes without waiting for standard input
  AND the new record stores the single-line description exactly as supplied
