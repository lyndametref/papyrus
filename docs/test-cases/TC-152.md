# TC-152 A record marked archived in the active folder is relocated when read

## Description
## Scenario: A record marked archived in the active folder is relocated when read

GIVEN a glossary record whose front-matter status is archived
  AND whose file is still in the type's active folder
WHEN a contributor views that record
THEN the record is returned
  AND the file has moved into the archived subfolder
  AND the run reports the relocation as a diagnostic finding
