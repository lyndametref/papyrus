Web · Managed artifacts & lifecycles

Managed artifacts and lifecycles

One section per managed record type. Backlog.md docs, drafts, and project configuration files are not covered.

Tasks

Curated description: tracked work items with a configurable status workflow.

Lifecycle: ToDo → Initiated → Refined → Implemented → Validated → Done.

Read-only config — enabled: true; ID prefix: TASK; storage folder: backlog/tasks. Statuses shown above. Changes via Configuration.

Milestones

Curated description: grouping of tasks toward a delivery goal.

Lifecycle: active → archived.

Read-only config — enabled: true; ID prefix: M; storage folder: backlog/milestones. Changes via Configuration.

Releases

Curated description: grouping of milestones toward a delivery.

Lifecycle: Draft → Released. A release becomes released when its milestone set is complete (REQ-03.002).

Read-only config — enabled: true; ID prefix: REL; storage folder: backlog/releases. Changes via Configuration.

Decisions

Curated description: recorded decisions with status and supersession.

Lifecycle: Proposed → Accepted → Superseded / Deprecated.

Read-only config — enabled: true; ID prefix: ADR; storage folder: docs/architecture/adr. Changes via Configuration.

Business requirements

Curated description: business requirement groups and atomic requirements.

Lifecycle: active → deprecated (restored via restore).

Read-only config — enabled: true; ID prefix: REQ; storage folder: requirements/business. Changes via Configuration.

Non-functional requirements

Curated description: non-functional requirement groups and atomic requirements.

Lifecycle: Draft → Approved → Deprecated / Restored.

Read-only config — enabled: true; ID prefix: NFR; storage folder: requirements/non-functional. Changes via Configuration.

Glossary terms

Curated description: glossary terms and definitions.

Lifecycle: Draft → Approved → Deprecated / Restored.

Read-only config — enabled: true; ID prefix: GLO; storage folder: domain-model/business-glossary. Changes via Configuration.

UI specifications

Curated description: UI specification records.

Lifecycle: Draft → Approved → Deprecated / Restored.

Read-only config — enabled: true; ID prefix: UI; storage folder: specifications/ui. Changes via Configuration.

Technical specifications

Curated description: technical specification records.

Lifecycle: Draft → Approved → Deprecated / Restored.

Read-only config — enabled: true; ID prefix: TECH; storage folder: specifications/technical. Changes via Configuration.

UI mockups

Curated description: UI mockup review packages.

Lifecycle: Draft → Approved → Deprecated / Restored. Approval explicit per mockup (REQ-05.008).

Read-only config — enabled: true; ID prefix: MOCK; storage folder: specifications/ui/mockups. Changes via Configuration.

Business rules

Curated description: business rules and applicability.

Lifecycle: Draft → Approved → Deprecated / Restored.

Read-only config — enabled: true; ID prefix: RUL; storage folder: business-rules. Changes via Configuration.

Audit records

Curated description: audit records with type and content.

Lifecycle: Created only; immutable once written. No state transitions.

Read-only config — enabled: true; ID prefix: AUD; storage folder: audit-records. Changes via Configuration.
