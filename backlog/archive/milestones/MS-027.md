## Description
Scope: remove the Configuration, Managed artifacts and lifecycles, and Agent skills and workflows sections from the local browser (REQ-06.018, ADR-034, TECH-080, UI-018). Acceptance criteria: AC-1 (REQ-06.018) browser navigation contains no entry for Configuration, Managed artifacts and lifecycles, or Agent skills and workflows; AC-2 (REQ-06.018) the configuration, lifecycle, and skills routes and their query aliases return 404 and are unreachable; AC-3 (REQ-06.018) configuration editing remains available through the CLI; AC-4 (REQ-06.018) managed-artifact and skill documentation remains available outside the browser and unchanged; AC-5 (REQ-06.018) the removal changes no record file and no configuration file; AC-6 (REQ-06.018) other browser pages and navigation continue to work; AC-7 (AUD-107, AUD-108) the full test suite is green except the pre-existing AUD-039 no_drift and characterization failures, and no stale reference to the removed surfaces remains in approved tests or verified specifications.
