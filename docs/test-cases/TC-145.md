# TC-145 An audit type write stores audit_type only in front matter with no body section

## Description
## Scenario: An audit type write stores audit_type only in front matter with no body section

GIVEN a project whose configuration declares the audit type
WHEN a contributor creates an audit record titled Access review with the audit-type option value licence
THEN the front matter carries the key audit_type with the value licence
  AND the body holds no audit-type section because the field is metadata-only and stored under its front-matter key
  AND viewing the record shows the licence value read from the front matter without a body duplicate
