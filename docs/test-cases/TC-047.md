# TC-047 Milestone create stores a multiline description supplied on standard input

## Description
## Scenario: Milestone create stores a multiline description supplied on standard input

GIVEN a Papyrus project with a backlog
  AND standard input carries a description of three lines
WHEN the user runs the milestone create command with the title "Multiline milestone" and the description supplied on standard input
THEN the command exits successfully and prints the new milestone ID
  AND viewing the milestone shows the three description lines in order, each on its own line
