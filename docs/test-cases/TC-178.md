# TC-178 Inventory latency stays under 250 ms at 1,000 records

## Description
## Scenario: Inventory latency stays under 250 ms at 1,000 records

GIVEN the reference hardware of 4 vCPU, 8 GiB RAM, SSD, Linux, one server process, loopback HTTP, and a release build with LTO and strip
  AND a corpus of 1,000 active records across the enabled document types
  AND the corpus includes a grouped type with a 200-member group and a mockup type with 50 records
WHEN the MS-032 benchmark harness performs 10 warm-up requests and then 100 measured sequential requests to the inventory page
  AND the first request after a cold start and any request that reloads the configuration are excluded
THEN the harness reports p50 and p95 latency as observed by the server
  AND the reported p95 is below 250 ms
  AND the harness command, corpus definition, and hardware are recorded with the result
