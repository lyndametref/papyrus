# TC-168 A config-defined type gains browser list, view, and edit views without a code change

## Description
## Scenario: A config-defined type gains browser list, view, and edit views without a code change

GIVEN a configuration that adds the SingleMarkdown type deploy with a prefix and a directory
  AND one deploy record exists
WHEN a contributor opens the deploy list, the record view, and the record edit form in the browser
THEN each page is served from the shared document surface using the type's label and directory
  AND the edit form offers the title control, the declared description field, labels, and references
  AND no status control is offered
