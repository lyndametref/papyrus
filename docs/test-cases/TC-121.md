# TC-121 A formatted-record mockup type offers no supersede and no status verb

## Description
## Scenario: A formatted-record mockup type offers no supersede and no status verb

GIVEN a project whose configuration enables the formatted-record type ui-mockup
WHEN a contributor requests help for the ui-mockup command
THEN the verb listing contains create, list, view, edit, archive, and delete
  AND it contains no status verb, no supersede verb, and no create-group verb
  AND the only state transition is an edit that sets the status to approved from draft
