# TC-051 Single-line metadata values containing embedded newlines are rejected

## Description
## Scenario: Single-line metadata values containing embedded newlines are rejected

GIVEN an existing request record with no labels
WHEN the user runs the request document edit command adding a label containing an embedded newline
THEN the command exits with the validation outcome exit code 4
  AND the record has no labels
