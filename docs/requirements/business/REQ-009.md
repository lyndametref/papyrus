# REQ-009 Search

## User Story

As a project contributor, I want to search all project records in one pass so that relevant backlog and documentation information is found quickly.

## Group

REQ-009 Search

## Criticality

Must have

## Description

This group covers the unified free-text search command over the backlog and document stores: one query across every managed record, optional record-type filters, a result limit, and the exclusion of archived records.
