# GLO-018 Field Specification

## Definition
A declaration of one content field of a document type: a stable key, exactly one storage location (a body heading or a front-matter key), a CLI option, a name and help text, a kind of text, multiline, or list, whether the field is required, and the verbs on which it may be set (a subset of create and edit). Its position in the field sequence is its order in the record body, in the command line, and in the browser form.

Also known as: FieldSpec, field.

Related terms: Document Type, Role, Record Model.
