# TC-111 A statuses list that declares active or archived is rejected

## Description
## Scenario: A statuses list that declares active or archived is rejected

GIVEN a user-defined type whose statuses list declares the values active and draft
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names document_types.deploy.statuses and states that neither active nor archived may be declared as a status
  AND the type has no command
