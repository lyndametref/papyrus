# TC-186 A conflicting directory change persists nothing and leaves both folders unchanged

## Description
## Scenario: A conflicting directory change persists nothing and leaves both folders unchanged

GIVEN a glossary directory whose content includes an entry named notes
  AND the target directory already holds an entry named notes
WHEN a contributor sets the glossary directory to the target path
THEN the command reports a conflict
  AND no configuration change is persisted
  AND both folders keep their original content
