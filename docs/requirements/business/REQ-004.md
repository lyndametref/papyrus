# REQ-004 Decision Records

## User Story
As a project decision-maker, I want to record, revise, settle, and retire decisions so that their history and current standing stay clear.

## Description
This group covers the decision record category (REQ-007.001): decision records, their types and content, status changes, supersession, and archiving. Records follow the Nygard ADR template and the fixed Nygard status vocabulary, shared by every decision type. Decision types are configured like document types — selected at init, each with a slug, a prefix, and a directory — and the folder layout depends on how many are configured. Content is editable and deletable only while a decision is proposed; status moves only through its verbs. Archiving moves the record into the decision folder's archive/ subfolder and leaves its status unchanged (REQ-004.002).
