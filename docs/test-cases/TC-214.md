# TC-214 Every compiled crate and bundled asset carries an OSI-approved GPL-compatible licence

## Description
## Scenario: Every compiled crate and bundled asset carries an OSI-approved GPL-compatible licence

GIVEN the dependency and bundled-asset licence audit list generated at build time
WHEN each entry is reviewed against the licence policy and the copyright notice
THEN every compiled crate and every bundled asset carries an OSI-approved licence compatible with GPL-3.0-or-later distribution
  AND the audit result is recorded with the release
  AND an incompatible licence blocks shipment

## Traceability
- Requirement: NFR-006.002
