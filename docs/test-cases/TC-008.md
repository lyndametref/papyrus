# TC-008 A POST whose Origin host is another allowed authority is accepted

## Description
## Scenario: A POST whose Origin host is another allowed authority is accepted

GIVEN an initialized Papyrus project with at least one editable record
  AND the browser server running on `127.0.0.1:<port>`
  AND a valid urlencoded edit form body for that record, including its current `version` token
WHEN a POST is sent whose `Origin` host is a different member of the allowed host set than the `Host` header
THEN the POST returns `303 See Other` (not `403`)
  AND the edits are persisted
