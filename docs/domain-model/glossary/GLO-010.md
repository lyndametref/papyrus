# GLO-010 Role

## Definition
The position that a document record and its field set take under a record model: single for a standalone record, group for a grouped type's group record, and member for a grouped type's member record. The role selects the field set that applies.

Also known as: record role, field-set role.

Related terms: Group Record, Member Record, Field Specification.
