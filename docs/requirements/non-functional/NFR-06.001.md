# NFR-06.001 License Papyrus Under GPLv3

## Description
Papyrus shall be licensed under GPLv3.

## Rationale
This records the requested project license without choosing an interpretation beyond the supplied GPLv3 designation.

## Verification Method
Review the project's licensing declaration and distributed license notice to confirm that GPLv3 is stated. Whether the intended license is GPL-3.0-only or GPL-3.0-or-later remains unspecified.
