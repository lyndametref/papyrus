# GLO-004 Task


## Definition
A tracked unit of work with a configurable status, description, acceptance criteria, labels, and assignees. A task may depend on other tasks, be assigned to zero or one milestone, carry a non-negative ordinal, and reference any managed record (REQ-002.001).
