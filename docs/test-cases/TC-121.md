# TC-121 A SingleHtmlMockup type offers supersede and no status verb

## Description
## Scenario: A SingleHtmlMockup type offers supersede and no status verb

GIVEN a project whose configuration enables the SingleHtmlMockup type ui-mockup
WHEN a contributor requests help for the ui-mockup command
THEN the verb listing contains create, list, view, edit, archive, delete, and supersede
  AND it contains no status verb and no create-group verb
