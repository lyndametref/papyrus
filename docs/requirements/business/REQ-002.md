# REQ-002 Task and Board Management

## User Story

As a project contributor, I want to record, organize, inspect, and track tasks so that project work is visible and can be managed through its lifecycle.

## Description

This group covers the task record type of the backlog artifact category (REQ-007.001): task records and their relationships, filtering and monitoring task lists, and task lifecycle actions. Tasks are the only backlog type with configurable statuses (`statuses`, `default_status`); milestone and release lifecycles are fixed (REQ-003).
