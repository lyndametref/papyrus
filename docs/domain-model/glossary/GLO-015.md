# GLO-015 Simple Record

## Definition
The record model in which each record stands alone, with a plain identifier, a Markdown body, and one field sequence that may be empty. A record of this model keeps status in front matter.

Also known as: single Markdown model.

Former name: SingleMarkdown (configuration value).

Related terms: Document Type, Field Specification, Role.
