# TC-109 An absent collection takes model defaults while a present collection replaces it

## Description
## Scenario: An absent collection takes model defaults while a present collection replaces it

GIVEN a configuration entry for glossary that omits its record_name and summary, declares slots as an empty sequence, and declares no fields
  AND a second document type whose slug is declared nowhere in the configuration
WHEN a contributor prints the effective configuration with config list
  AND runs a command of the undeclared slug
THEN each omitted glossary attribute takes its model-level default: a slug-derived record_name, an empty summary, and one optional multiline content field stored directly in the body without a heading
  AND the declared empty slots remain empty
  AND no seed value fills any omitted attribute, because the Seed is only an init-time convenience
  AND the undeclared slug offers no command, because a document type exists only when the configuration declares it
