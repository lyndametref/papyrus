# TC-141 A ui-spec create that supplies only a title is valid and keeps field order

## Description
## Scenario: A ui-spec create that supplies only a title is valid and keeps field order

GIVEN a project whose configuration enables the ui-spec type
WHEN a contributor creates a UI specification with only the title Checkout screen
THEN the create succeeds and the record has the status active
  AND the record body has no View or Description section
  AND a later edit supplying view and description writes View before Description
