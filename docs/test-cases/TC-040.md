## Scenario: Document create stores a multiline description supplied on standard input

GIVEN a Papyrus project whose configuration enables the request document type
  AND standard input carries a description of three lines
WHEN the user runs the request document create command with the title "Multiline request" and the description supplied on standard input
THEN the command exits successfully and prints the new record ID
  AND viewing the new record shows the three description lines in order, each on its own line
