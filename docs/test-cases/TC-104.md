# TC-104 An unknown field kind is rejected with its selector path

## Description
## Scenario: An unknown field kind is rejected with its selector path

GIVEN a user-defined type whose declared description field sets the kind paragraph
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names document_types.deploy.fields[description].kind
  AND the diagnostic states that the kind must be text, multiline, or list
