# GLO-019 Role

## Definition
The position that a document record and its field set take under a document model: single for a standalone record, group for a grouped type's group record, and member for a grouped type's member record. The role selects the field set and the reference visibility that apply.

Also known as: record role, field-set role.

Related terms: Document Model, Group Record, Member Record, Field Specification.
