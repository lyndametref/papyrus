# NFR-002.002 Input Sanitization

## Description

Papyrus shall sanitize every user-supplied value from CLI options, standard input, and browser forms before use. A value that cannot be normalized into a valid identifier, name, title, or path shall be rejected; no invalid value is silently cleaned, truncated, or written.

## Rationale

One sanitization contract for every input path keeps control characters, traversal segments, and malformed records out of the store.

## Verification Method

Exercise every CLI option class and browser form field with valid, empty, control-character, path-separator, and traversal values. Confirm that valid values are stored and that every invalid value is rejected with an error, with no silent cleaning and no record written.
