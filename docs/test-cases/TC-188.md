# TC-188 Changing a type directory moves the folder content during the set command

## Description
## Scenario: Changing a type directory moves the folder content during the set command

GIVEN a glossary directory holding managed records and an unmanaged subfolder
WHEN a contributor sets the glossary directory to a new path
THEN every file and subfolder moves to the new path during the set command
  AND the original folder no longer holds the moved content
  AND the new configuration value is persisted
