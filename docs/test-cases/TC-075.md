# TC-075 Ordinal ordering does not change release grouping or the tasks-without-a-milestone section

## Description
## Scenario: Ordinal ordering does not change release grouping or the tasks-without-a-milestone section

GIVEN milestones assigned to releases and tasks without a milestone
WHEN a contributor opens the Backlog view
THEN milestones remain grouped under their releases
  AND the no-release group precedes all releases
  AND tasks without a milestone appear in their section after all milestone sections
