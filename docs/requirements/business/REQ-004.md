# REQ-004 Decision Records

## User Story

As a project decision-maker, I want to capture, find, and update decisions so that the rationale and status of project decisions can be reviewed later.

## Description

This group covers the decision artifact category (REQ-007.001): decision records, their types and content, status changes, and supersession. Decision records follow the Nygard ADR template and a fixed status vocabulary; their statuses are not configurable. The decision status `deprecated` is a Nygard status and is not the document state `archived` (REQ-005.007).
