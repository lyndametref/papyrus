# TC-135 A req list merges group rows and member rows in group then member order

## Description
## Scenario: A req list merges group rows and member rows in group then member order

GIVEN two requirement groups REQ-001 and REQ-002
  AND REQ-001 holds two members and REQ-002 holds one member
WHEN a contributor lists the requirement records
THEN the rows appear as REQ-001, its members in member order, REQ-002, then its member
  AND each group row is followed by its own members only
