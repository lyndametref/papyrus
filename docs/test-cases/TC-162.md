# TC-162 A test-case create supplies only a title and exposes the status verb

## Description
## Scenario: A test-case create supplies only a title and exposes the status verb

GIVEN a project whose configuration enables the test-case type
WHEN a contributor creates a test case titled Archive a record with only a title
  AND requests help for the test-case command
THEN the record has the status active and a TC prefix
  AND the help offers the status verb and the description and applicability options in that order
  AND no extension verb is offered
