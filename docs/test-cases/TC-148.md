# TC-148 Archiving a document moves it to the archived subfolder and keeps its ID

## Description
## Scenario: Archiving a document moves it to the archived subfolder and keeps its ID

GIVEN an active glossary record GLO-003 stored in the type's active folder
WHEN a contributor archives that record
THEN the record's status is archived
  AND the file is stored in the archived subfolder of the type's directory
  AND the record still has the ID GLO-003
  AND the record is hidden from the list, search, and browser views
