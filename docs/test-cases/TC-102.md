# TC-102 A user-defined slug gains a SingleMarkdown command with the documented defaults

## Description
## Scenario: A user-defined slug gains a SingleMarkdown command with the documented defaults

GIVEN a configuration that adds the document type deploy with only a prefix and a directory
WHEN a contributor lists the available commands
  AND creates a deploy record with a title
THEN the deploy command is available with the verbs of a SingleMarkdown type
  AND the new record has a plain ID under the DEP prefix and the status active
  AND the record's only declared field is an optional multiline description
