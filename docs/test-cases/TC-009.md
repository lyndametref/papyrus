# TC-009 A POST with Host and Origin on different allowed loopback authorities is accepted

## Description
## Scenario: A POST with Host and Origin on different allowed loopback authorities is accepted

GIVEN an initialized Papyrus project with at least one editable record
  AND the browser server running on `127.0.0.1:<port>`, so the allowed authorities are `127.0.0.1:<port>` and `localhost:<port>`
  AND a valid urlencoded edit form body for that record, including its current `version` token
WHEN a browser edit form POST is sent whose `Host` header names `localhost:<port>` and whose `Origin` is `http://127.0.0.1:<port>`
THEN the POST returns `303 See Other` (not `403`)
  AND the edits are persisted to the record file
