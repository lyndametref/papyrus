# TC-105 A reserved key used as a field key or front-matter key is rejected

## Description
## Scenario: A reserved key used as a field key or front-matter key is rejected

GIVEN a user-defined type whose field uses title as its key
  AND whose second field uses status as its front-matter key
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND each diagnostic names the offending field location and the reserved key
  AND the type is not usable as a command
