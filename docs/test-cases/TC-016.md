# TC-016 Milestone archive moves a closed milestone to the archive folder and keeps its status

## Description
## Scenario: Milestone archive moves a closed milestone to the archive folder and keeps its status

GIVEN an initialized Papyrus project with a closed milestone MS-002
WHEN the user runs `papyrus milestone archive MS-002`
THEN the status stays `closed` and no close step is performed
  AND the file is moved to `backlog/milestones/archive/MS-002.md`
  AND `updated_date` is refreshed once
  AND title, description, labels, references, and release assignment are preserved
  AND the command exits 0 and prints the milestone ID
