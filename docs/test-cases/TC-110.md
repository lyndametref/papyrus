# TC-110 A slug that collides with a built-in command name is rejected case-insensitively

## Description
## Scenario: A slug that collides with a built-in command name is rejected case-insensitively

GIVEN a document-type entry whose slug is Config
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names the configuration entry and the built-in command conflict
  AND the built-in config command still behaves as before
