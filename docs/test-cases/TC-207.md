# TC-207 The help command prints the manual and per-command help without reading records

## Description
## Scenario: The help command prints the manual and per-command help without reading records

GIVEN an initialized project
WHEN the user runs `papyrus help`
  AND `papyrus help <COMMAND>` for a built-in command and a configured slug
  AND `papyrus help NO-SUCH-COMMAND`
THEN `papyrus help` prints the manual with the same content as `man papyrus`
  AND `papyrus help <COMMAND>` prints that command's help as `--help` does
  AND the unknown command is a usage error with exit code 2 that names the command
  AND no record is read and nothing is written
