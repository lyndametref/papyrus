# TC-194 A formatted-record edit form offers title and references with no labels control

## Description
## Scenario: A formatted-record edit form offers title and references with no labels control

GIVEN a project whose configuration enables the formatted-record type ui-mockup
  AND an existing mockup record
WHEN a contributor opens the mockup's browser edit form
THEN the form offers the fixed title control and the `references` control
  AND `status` and the created and updated dates are shown read-only
  AND no `labels` control is offered
