# REQ-006.002 Serve the Local Web Interface

## User Story

As a project contributor, I want to open a local web interface over project stores so that I can access project information through a browser.

## Group

REQ-006 Search and Local Web Interface

## Criticality

Must have

## Description

The browser command serves the local web UI over backlog, decision, and document records. Its default bind address is `127.0.0.1`, and there is no default port: when no port is selected, the command chooses a free port above 1024 and below 9999, retrying with another port when one is taken, and reports the chosen address when it starts. The host and the port can be selected; a selected port is used as given, and an unavailable selected port fails with a conflict outcome. A non-loopback host is permitted but causes a warning. The default browser opens automatically unless disabled by option or configuration.

## Acceptance Criteria

- `papyrus browser` starts the web UI over backlog, decision, and document records using the selected host and port.
- The default host is `127.0.0.1` and there is no default port.
- With no selected port, the command chooses an unused port above 1024 and below 9999 and reports the chosen address when it starts.
- When the chosen port is taken, the command retries with another port until one is free.
- A selected port is used as given, and an unavailable selected port fails with a conflict outcome.
- A user-specified non-loopback host is accepted and causes a warning.
- `--no-open` prevents automatic opening of the default browser.
