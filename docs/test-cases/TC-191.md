# TC-191 A keyed and an indexed field selector resolve to the same configuration leaf

## Description
## Scenario: A keyed and an indexed field selector resolve to the same configuration leaf

GIVEN the req group field sequence begins with the story field
WHEN a contributor reads document_types.req.group.fields[story].heading
  AND reads document_types.req.group.fields[0].heading
THEN both reads print the same heading value
  AND changing the leaf through either selector changes the same effective value
