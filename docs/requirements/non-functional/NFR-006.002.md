# NFR-006.002 GPL-Compatible Dependency Licenses

## Description

Every crate compiled into the Papyrus binary and every bundled third-party asset shall be open source and licensed so that it can be distributed in a GPL-3.0-or-later application. Open source means an OSI-approved license.

## Rationale

One license rule keeps the distributed package redistributable under GPL-3.0-or-later.

## Verification Method

Inspect the dependency and bundled-asset license audit and the distributed copyright notice; confirm that every compiled crate and every bundled asset carries an OSI-approved license compatible with distribution under GPL-3.0-or-later, and record the audit result with the release.
