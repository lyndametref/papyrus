# REQ-002 Backlog Management

## User Story
As a project contributor, I want to manage tasks, milestones, and releases in one place so that planned work is organized, tracked, and closed out.

## Description
This group covers the backlog artifact category (REQ-007.001): the task, milestone, and release record types, their attributes and command families, and their lifecycles. Task statuses are configurable; milestone and release lifecycles are fixed. The group owns management (REQ-002.001, REQ-002.003, REQ-002.004) and the shared read-only surface (REQ-002.002) of the whole category.
