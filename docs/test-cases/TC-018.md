# TC-018 Milestone archive refuses invalid status with exit code 4

## Description
## Scenario: Milestone archive refuses invalid status with exit code 4

GIVEN an initialized Papyrus project with a milestone MS-004 whose stored status is neither `open` nor `closed` (the milestone status vocabulary has no other value)
WHEN the user runs `papyrus milestone archive MS-004`
THEN the command exits 4 with a validation outcome
  AND the error names the milestone's stored status
  AND no file is written or moved
