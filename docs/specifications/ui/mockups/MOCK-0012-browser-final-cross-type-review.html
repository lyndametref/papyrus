Managed artifacts and lifecycles

One section per fixed record type. Backlog.md docs, drafts, and project configuration files are excluded.

Tasks

States derived from configured statuses (REQ-01.002); example set: To Do → In Progress → Done. Transitions follow configured status order.

Milestones

Open → Closed. A milestone closes when its tasks are complete; reopening restores Open.

Releases

Draft → Released. A release becomes released when its milestone set is complete (REQ-03.002).

Decisions

Proposed → Accepted → Superseded / Deprecated.

Business requirements

Draft → Approved → Deprecated / Restored (REQ-05.007).

Non-functional requirements

Draft → Approved → Deprecated / Restored.

Glossary terms

Draft → Approved → Deprecated / Restored.

UI specifications

Draft → Approved → Deprecated / Restored.

Technical specifications

Draft → Approved → Deprecated / Restored.

UI mockups

Draft → Approved → Deprecated / Restored. Approval explicit per mockup (REQ-05.008).

Business rules

Draft → Approved → Deprecated / Restored.

Audit records

Created only; immutable once written. No state transitions.
