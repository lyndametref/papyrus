# TC-174 ID padding is a minimum and a wider record number is never truncated

## Description
## Scenario: ID padding is a minimum and a wider record number is never truncated

GIVEN a project with id_padding 2
  AND requirement records up to number 99 exist
WHEN a contributor creates the next requirement group
THEN the new group ID uses the full number 100 as REQ-100
  AND a member under it uses the dotted ID REQ-100.01
  AND no ID digit is truncated
