# UI-018 Papyrus Local Browser (Navigation without Removed Sections)

## View
browser-navigation-without-removed-sections

## Description
Ticket TASK-171. Removes Configuration, Managed artifacts and lifecycles, and Agent skills and workflows entries and routes from the browser shell navigation (REQ-06.018, RE-005, ADR-034, TECH-080, NFR-01.002). The Project group is removed from the document-types sidebar; no nav entry or route remains for the three sections. Configuration editing remains via CLI (papyrus config); managed-artifact and skill documentation remains outside the browser. Underlying records and configuration files unchanged; other pages and navigation continue to work. Platforms: web only (local browser); desktop frame; responsive behavior inherited from shared shell (UI-016). Active elements: sidebar document-type links, navigation toggle, breadcrumb links, record view and edit links. States: none added; happy path only. UI spec stays draft until mockup approval.
