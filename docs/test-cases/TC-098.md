# TC-098 A new document record starts at its type's configured default status

## Description
## Scenario: A new document record starts at its type's configured default status

GIVEN a document type whose configuration declares the statuses active, draft, review, and archived
  AND that type declares draft as its default status
WHEN a contributor creates a record of that type with a title
THEN the new record carries the front-matter status draft
  AND the record is stored in the type's active folder
  AND the record appears in the type's list
