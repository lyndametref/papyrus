# TC-064 Removing the list reference display changes no record or front matter

## Description
## Scenario: Removing the list reference display changes no record or front matter

GIVEN a project whose records carry references in their front matter
WHEN the reviewer opens the document-type list views
  AND each record file is compared with its content before the change
THEN every record file still contains its reference entries in the front matter
  AND no record file or configuration file is modified by the list rendering

## Traceability
- Requirement: REQ-06.019
- Business rules: none
- Milestone acceptance: MS-028 AC-6 (no underlying record or front-matter value is changed)
