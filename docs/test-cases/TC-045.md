# TC-045 Task create stores a multiline description supplied on standard input

## Description
## Scenario: Task create stores a multiline description supplied on standard input

GIVEN a Papyrus project with a backlog
  AND standard input carries a description of three lines
WHEN the user runs the task create command with the title "Multiline task" and the description supplied on standard input
THEN the command exits successfully and prints the new task ID
  AND viewing the task shows the three description lines in order, each on its own line
