# TC-171 A stale version token returns 409 with the edit form and writes nothing

## Description
## Scenario: A stale version token returns 409 with the edit form and writes nothing

GIVEN a glossary record opened in two browser edit forms
  AND the record is saved from the first form
WHEN the second form is submitted with its now stale version token
THEN the response has status 409 and renders the edit form with the submitted values and a conflict notice
  AND the shared document surface writes no change
  AND the record still holds the first form's value
