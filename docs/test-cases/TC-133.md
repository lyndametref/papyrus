# TC-133 A req group and its members carry plain and dotted IDs

## Description
## Scenario: A req group and its members carry plain and dotted IDs

GIVEN a project whose configuration enables the grouped type req
WHEN a contributor creates a requirement group titled Billing
  AND creates a member titled Invoices under that group
THEN the group has a plain ID of the form REQ-nnn
  AND the member has a dotted ID of the form REQ-nnn.001 under the same group sequence
  AND the member's front matter carries the engine-owned group key naming the group
  AND neither the create help nor the edit help offers a group option
