# TC-165 An undeclared front-matter key is shown read-only in CLI and browser

## Description
## Scenario: An undeclared front-matter key is shown read-only in CLI and browser

GIVEN a glossary record whose front matter carries the undeclared key owner with the value platform
WHEN a contributor views the record in the CLI and in the browser
THEN both surfaces display owner with the value platform after the declared fields
  AND the browser shows it as read-only metadata
  AND saving the record does not remove or rewrite the key
