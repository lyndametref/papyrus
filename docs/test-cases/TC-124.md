# TC-124 A create that omits a required field writes no file

## Description
## Scenario: A create that omits a required field writes no file

GIVEN a project whose configuration enables the rule type
  AND the rule type requires description, rationale, and applicability
WHEN a contributor creates a rule with a title, a description, and a rationale but no applicability
THEN the create reports one validation outcome and exit code 4
  AND the outcome names applicability as missing
  AND no rule record is written
