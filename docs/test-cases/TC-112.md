# TC-112 A default status that is archived is rejected

## Description
## Scenario: A default status that is archived is rejected

GIVEN a user-defined type whose default status is archived
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names document_types.deploy.default_status
  AND no new record can start archived
