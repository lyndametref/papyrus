# TC-192 An unknown, archived, or unconfigured document address returns the same not-found page

## Description
## Scenario: An unknown, archived, or unconfigured document address returns the same not-found page

GIVEN an archived document record, an unknown document ID, and a type that is not configured
WHEN a contributor requests each of those records in the browser
THEN each response has status 404 and renders the same not-found page
  AND no archived record content or unconfigured type content is shown
