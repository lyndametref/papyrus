# TC-021 Milestone list hides archived milestones

## Description
## Scenario: Milestone list hides archived milestones

GIVEN an initialized Papyrus project containing an archived milestone MS-006 and an open milestone MS-007
WHEN the user runs `papyrus milestone list`
THEN MS-006 is not listed
  AND MS-007 is listed
  AND only open and closed milestones appear in the output
