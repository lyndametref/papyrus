# GLO-003 Release


## Definition
A grouping for milestones that has the fixed planned -> released lifecycle; `papyrus release close` releases it. `papyrus release archive` moves its file to `<backlog_dir>/<release_dir>/archive` with the status unchanged; archiving or deleting a release changes no milestone (REQ-002.006, REQ-007.001).
