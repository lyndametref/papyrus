# TC-140 Renaming a glossary term keeps its ID, path, and ID references

## Description
## Scenario: Renaming a glossary term keeps its ID, path, and ID references

GIVEN a glossary record GLO-002 titled Cache referenced by ID from a technical specification
WHEN a contributor renames the record title to Caching
THEN the record is still GLO-002 at the same file path
  AND the technical specification reference still resolves to the record
  AND the definition is unchanged

GLO-002 is a test-fixture identifier used in an isolated test project; it is not a reference to a glossary term in this corpus.
