# TC-182 The benchmark protocol measures the 1,000-record corpus with warm-up and recorded hardware

## Description
## Scenario: The benchmark protocol measures the 1,000-record corpus with warm-up and recorded hardware

GIVEN the benchmark harness and its corpus of 1,000 active records across the enabled document types
WHEN the harness runs on the reference hardware with one server process, loopback HTTP, and a release build with LTO and strip
THEN the harness performs its documented warm-up requests before the measured runs
  AND the measured runs are sequential and exclude the cold-start request and configuration reloads
  AND the harness reports p50 and p95 for inventory, view, and edit
  AND the run records the exact harness commands, the corpus definition, and the hardware description
