# TC-068 A milestone with no non-archived task appears after milestones with tasks in its group

## Description
## Scenario: A milestone with no non-archived task appears after milestones with tasks in its group

GIVEN a release group contains milestones MS-005 and MS-006
  AND MS-005 has non-archived task TASK-005 with ordinal 10
  AND MS-006 has no non-archived task
WHEN a contributor opens the Backlog view
THEN MS-005 appears before MS-006
  AND MS-006 appears after every milestone with a non-archived task in that group
