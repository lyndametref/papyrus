## Scenario
An `Origin` containing an IPv6 host is normalized (bracketed and unbracketed forms) and accepted when that host is in the allowed host set.

## Preconditions
- An initialized Papyrus project with at least one editable record.
- The browser server running on `[::1]:<port>` (or `127.0.0.1:<port>` with `::1` in the allowed host set).
- A valid urlencoded edit form body for that record, including its current `version` token.

## Steps
1. Render the edit form for an existing record and capture its `version` token.
2. Send `POST /doc/<record-id>` with `Host: [::1]:<port>`, `Origin: http://[::1]:<port>`, and the valid form body.
3. Send `POST /doc/<record-id>` with `Host: [::1]:<port>`, `Origin: http://::1:<port>`, and the valid form body.

## Expected outcome
- Both POSTs return `303 See Other` (not `403`).
- IPv6 brackets do not cause a mismatch.
