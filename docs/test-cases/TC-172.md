# TC-172 config list prints model-level defaults addressed by selector paths

## Description
## Scenario: config list prints model-level defaults addressed by selector paths

GIVEN a configuration whose glossary entry declares no record_name and no fields
WHEN a contributor runs config list
THEN the output includes the slug-derived record_name and the default multiline content field of glossary
  AND each leaf is addressed by its selector path
  AND field properties are addressed with the keyed field selector form
  AND no value comes from the Seed
