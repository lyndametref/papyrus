# NFR-01.001 Provide Papyrus as a Command-Line Tool

## Description

## Rationale
This records the confirmed product form so the product scope and its verification remain aligned.

## Verification Method
Review the documented product entry point and invocation instructions to confirm that Papyrus is provided as a command-line tool.
