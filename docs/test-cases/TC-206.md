# TC-206 The installed packages provide the manual pages at the standard paths

## Description
## Scenario: The installed packages provide the manual pages at the standard paths

GIVEN the built `papyrus` and `papyrus-browser` packages installed on the target
WHEN the user runs `man papyrus`, `man papyrus-config`, and `man papyrus-browser`
THEN each page is displayed from the standard manual path
  AND `papyrus(1)` documents every built-in command and the `<slug>` family once
  AND no per-type manual page is shipped
  AND the pages need no network access
