# TC-114 config set materializes only the target entry and applies one change

## Description
## Scenario: config set materializes only the target entry and applies one change

GIVEN a project configuration file that declares no document_types entry
WHEN a contributor sets document_types.req.enabled to false
THEN the configuration file gains one req entry carrying its prefix and directory and the disabled value
  AND no other seed entry is written to the file
  AND the other seed types remain effective from the seed set
