# NFR-05.001 Display the Browser Interface in Named Browsers

## Description
The Papyrus browser interface shall display in Firefox, Microsoft Edge, and Safari.

## Rationale
This records the requested browser support without assuming browser versions or defining visual behavior not supplied in the scope.

## Verification Method
Open the browser interface in Firefox, Microsoft Edge, and Safari and confirm that it renders in each. Specific versions and criteria for what constitutes displaying properly remain unspecified.
