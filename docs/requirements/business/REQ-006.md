# REQ-006 Local Web Interface

## User Story
As a project contributor, I want to browse project records in a local web interface so that backlog and documentation can be read and edited in one place.

## Description
This group covers the local web interface: serving it over the project stores, the shared list and record views, the document surface for every configured type, links between records, console verbosity, the glossary landing page, the Backlog board, the rendering of math and diagrams, and the parity between command-line and browser metadata.
