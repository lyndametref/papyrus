# NFR-003.003 Packaged Man Pages

## Description

Every built-in command shall have a man page, and those man pages shall be installed with the package. Man page sources shall be Markdown files, generated to roff at build time and installed to the standard man paths. The document-command family is documented once in the manual, not per configured type.

## Rationale

The man pages are the packaged help surface and must ship with the commands they document.

## Verification Method

Inspect the installed package: confirm that a man page is installed for every built-in command, that roff pages are installed under the standard man paths and generated from Markdown sources, and that each page matches the command's documented behavior.
