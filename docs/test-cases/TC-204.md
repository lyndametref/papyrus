# TC-204 The browser console is quiet by default and --debug logs one line per request

## Description
## Scenario: The browser console is quiet by default and --debug logs one line per request

GIVEN a running `papyrus-browser`
WHEN requests are served without `--debug`
THEN only errors are output to the console
WHEN the server runs with `--debug` and receives requests
THEN each received request is logged as one line with method, path, response status, and duration
  AND request headers and bodies are not logged
  AND `--debug` is not accepted by any `papyrus` command or global option
