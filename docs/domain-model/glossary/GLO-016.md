# GLO-016 GroupedMarkdown

## Definition
The document model whose records form groups: a group record with a plain identifier and member records with dotted identifiers, each carrying a Markdown body and its own role field set.

Also known as: grouped Markdown model.

Related terms: Document Model, Group Record, Member Record, Role, Field Specification.
