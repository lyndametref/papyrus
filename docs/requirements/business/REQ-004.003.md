# REQ-004.003 Inspect Decisions

## User Story

As a project contributor, I want to read decisions and find them by type so that the reasoning behind the project is available.

## Group

REQ-004 Decision Records

## Criticality

Must have

## Description

**View.** `papyrus <slug> view <ID>` shows a decision's identifier, title, type, status, decision text, context, consequences, creation date, update date, labels, references, and, when it has been superseded, its successor. A decision that has been moved into the archive folder remains viewable, and an edit is rejected with a validation outcome (REQ-004.002).

**List.** `papyrus <slug> list` prints the decisions as plain text by default and honours the global `--json` option (REQ-001.004). The `papyrus <slug> list` command lists the decisions of that type; it shows the identifier, title, type, status, creation date, and update date of each. Decisions moved to the archive folder are excluded, and a cross-type listing is provided by search (REQ-009.001) rather than by a shared command.

## Acceptance Criteria

- `papyrus <slug> view <ID>` shows the identifier, title, type, status, decision text, context, consequences, creation date, update date, labels, and references.
- A superseded decision's view names its successor.
- A decision moved to the archive folder remains viewable, and an edit is rejected with a validation outcome.
- `papyrus <slug> list` shows the identifier, title, type, status, creation date, and update date of each decision.
- `papyrus <slug> list` lists only the decisions of that type, and a cross-type listing is provided by search.
- Archived decisions are excluded from the list.
- The list prints plain text by default and honours the global `--json` option.
