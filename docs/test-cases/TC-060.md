# TC-060 JSON record output keeps references for generic document types

## Description
## Scenario: JSON record output keeps references for generic document types

GIVEN a config-defined document type record that carries references in its front matter
WHEN the record is read through the JSON API
THEN the response contains the record references in their stored order
  AND the remaining metadata values are unchanged
