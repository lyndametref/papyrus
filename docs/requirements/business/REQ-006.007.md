# REQ-006.007 Limit Browser Console Verbosity

## User Story

As a project contributor, I want the browser command to be quiet in the console unless debugging is enabled so that normal operation is not noisy.

## Group

REQ-006 Search and Local Web Interface

## Criticality

Should have

## Description

The browser is very verbose in the console. A `--debug` option shall show received requests; otherwise only errors shall be output to the console. `--debug` is an option of the `papyrus-browser` binary only; it is not a global option of `papyrus` and is not accepted by any other command. With `--debug`, each received request is logged as one line with method, path, response status, and duration; request headers and bodies are not logged, so record content does not leak into the console.

## Acceptance Criteria

- By default, the papyrus-browser binary outputs only errors to the console.
- With `--debug`, received requests are logged to the console.
- `--debug` is a papyrus-browser-only flag; no command of `papyrus` and no global option accepts it.
- Each logged request is one line containing the method, path, response status, and duration.
- Request headers and bodies are not logged.
- Errors are output whether or not `--debug` is set.
