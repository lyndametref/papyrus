# TC-187 App assets revalidate with one strong entity tag

## Description
## Scenario: App assets revalidate with one strong entity tag

GIVEN a running server built from the refactor
WHEN a contributor requests an app stylesheet or script
THEN the response has status 200 with no-cache caching and one strong entity tag
  AND a request whose If-None-Match matches receives a bodyless 304 with the same entity tag and cache directive and no content type or length
  AND a request with a non-matching or unparseable tag receives the full 200
