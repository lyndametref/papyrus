# REQ-006.011 Adjust Glossary Landing Page Display

## User Story

As a project contributor, I want the glossary landing page to show labels as tags without dates or references so that it stays concise.

## Group

REQ-006 Search and Local Web Interface

## Criticality

Could have

## Description

In the glossary landing page, created and updated dates are removed, labels are shown as a list of tags, and references are not shown. "Tags" means the taglist presentation used for labels in single record views (REQ-006.012). The change is limited to the glossary landing (list) page; glossary detail views follow REQ-006.012, and other document types are unchanged.

## Acceptance Criteria

- The glossary landing page omits created and updated dates.
- Labels are shown as a list of tags on the glossary landing page, using the same taglist presentation as REQ-006.012.
- References are not shown on the glossary landing page.
- Glossary detail views are unchanged by this requirement and follow REQ-006.012.
- Other document-type landing pages are unchanged.
