# TC-119 A SingleMarkdown type exposes the baseline verbs plus status

## Description
## Scenario: A SingleMarkdown type exposes the baseline verbs plus status

GIVEN a project whose configuration enables the SingleMarkdown type glossary
WHEN a contributor requests help for the glossary command
THEN the verb listing contains create, list, view, edit, archive, delete, and status
  AND it contains no create-group, supersede, deprecate, or restore verb
