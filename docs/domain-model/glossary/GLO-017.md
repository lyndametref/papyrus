# GLO-017 Formatted Record

## Definition
The record model in which records have an HTML body, a plain identifier, no field sequence, and fixed metadata states in the HTML metadata comment instead of front matter. The states are pending, approved, and archived.

Also known as: HTML mockup model.

Former name: SingleHtmlMockup (configuration value). The term "Formated Recorded" was corrected to "Formatted Record".

Related terms: Document Type, Role.
