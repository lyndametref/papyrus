# REQ-01.001 Sheep Identification

## User Story

As a shepherd, I want to assign a unique identifier to each sheep so that I can track it throughout its life in the flock.

## Group

REQ-01 Individual Management

## Criticality

Must have

## Description

Each sheep in the flock must be assigned a unique identifier at registration. The identifier must be immutable and used as the primary reference for all records associated with that sheep.

## Acceptance Criteria

- Each sheep receives a unique identifier upon registration
- The identifier is immutable once assigned
- The identifier is used as the primary key for all sheep-related records
- No two sheep can share the same identifier
