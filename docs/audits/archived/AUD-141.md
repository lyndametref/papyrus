# Code audit MS-034 field-driven CLI engine

## Scope

- MS-034 CLI engine, change set 73a4f53..HEAD (TASK-255, 256, 257, 258, 259, 260, 308 all Done).
- Files: src/document.rs, src/config.rs, src/registry.rs, src/record/{patch,store,frontmatter,document}.rs, src/ui_mockup.rs, src/commands.rs, src/sanitize.rs, src/cli/tree.rs, tests and goldens.
- Out of scope: backlog and decision modules, browser presentation consolidation (MS-035), legacy data migration.

## Checks run

- cargo fmt --check clean; cargo clippy --all-targets -- -D warnings clean.
- cargo test: 1261 passed, 0 failed, 26 ignored, 66 suites.
- Manual CLI probes for title edge cases, stdin on create and create-group, group reference shapes, mockup metadata round-trips, YAML scalar edge cases, config-declared role fields, archived edits, concurrent creates.

## Verified behaviours

- Create seeds status for every Markdown model from default_status or active; mockup keeps pending in HTML metadata.
- status rejects archived and names archive; archive sets archived; no option sets status.
- Title unicode accepted; empty, whitespace, newline, control and dual sources rejected with exit 4 and no write; edit cannot clear.
- Group link written once as the reserved front-matter key; edit leaves it unchanged.
- Paths canonicalized and contained; group references restricted to prefix plus digits.

## Findings

### High

F1 create-group bypasses the shared create pipeline: no stdin resolution, no required-field enforcement, frontmatter_key and field_defaults dropped (src/document.rs:831-894). Correction: use resolve_field_stdin, ensure_required_fields and the shared create-op builder.
F2 ID allocation is scan-then-rename and can overwrite records: 12 concurrent tech-spec creates produced 2 files with exit 0 (src/document.rs:741-755, 846-847; src/record/store.rs:366). Correction: reserve IDs atomically with create_new or no-replace link and retry on AlreadyExists; add a concurrency regression test.
F3 Accepted titles and labels can write invalid or type-changing YAML: titles starting with YAML indicators break the next command, and a bracketed title becomes a sequence (src/record/frontmatter.rs:263-291, 311-343; src/document.rs:771-807). Correction: quote YAML-unsafe scalars, never coerce scalars to sequences, re-parse rendered front matter before writing, add round-trip tests.
F4 HTML mockup metadata is unescaped and asymmetric: a title can set status on an unrelated edit and entities are rewritten (src/ui_mockup.rs:390-411, 322-388). Correction: escape every rendered field, parse metadata only from the fixed comment block, preserve the raw title, add injection tests.

### Medium

F5 --group references are not normalized (req view REQ-1 works but create --group REQ-1 fails). Correction: resolve through resolve_in_dirs and use the canonical ID.
F6 Edit mixes group and member role fields. Correction: resolve the role first, use only that role's fields, reject undeclared options with one validation outcome.
F7 Config validation gaps: field key or option label panics (exit 101), json shadows the global flag, cross-role duplicate option panics, ui-mockup fields accepted and ignored, empty derived option accepted. Correction: reserved option names, cross-role duplicates, mockup field rejection, empty option rejection, with a tree-build test for every descriptor.
F8 Title sanitizer rejects legal titles (CI/CD, A backslash B). Correction: title-specific sanitizer without path rules.
F9 Field and role resolution duplicated in engine and registry. Correction: one shared function.
F10 Vacuous or ambiguous tests: handler assertion is a tautology, req_errors accepts two causes, missing-title test only checks is_err. Correction: assert concrete handlers, messages and no-write.

### Low

F11 Archived-edit guard unreachable for config-defined types; edit returns exit 3 not found. Correction: resolve archived or delete the dead branch and document.
F12 Dead code and stale docs: duplicate list readers, unreachable Supersede arm, unused CreateOptions, stale module comments, stale allow attributes.
F13 Second slug table (document_handler) outside the seed. Correction: carry the legacy handler in the seed or add a drift test.
F14 Legacy group sections cannot take new members. Decision and fixture required.
F15 Labels and references use a string sentinel instead of the sequence API. Correction: use FrontMatterValue::Sequence everywhere.

## Severity counts

blocker 0, high 4, medium 6, low 5.

## Verdict

corrections required - the engine meets the model matrix and normal-case title, group and status contracts, but four high findings cover silent record loss, unreadable records from accepted input, a create-group validation bypass and mockup metadata injection.
