# TC-055 Generic document-type list rows omit the reference list

## Description
## Scenario: Generic document-type list rows omit the reference list

GIVEN a project with the config-defined document type Notes
  AND several Notes records that carry references and labels
WHEN a reviewer opens the Notes list view
THEN no row shows a reference list
  AND no row shows an empty, collapsed, or expandable reference element
  AND every row still shows the record title and its labels

- Requirement: REQ-06.019
