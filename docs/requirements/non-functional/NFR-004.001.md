# NFR-004.001 Text-File Storage

## Description

All data saved by Papyrus shall be stored as UTF-8 text files with no binary content: Markdown for managed records other than UI mockups, HTML for UI mockup records, and YAML for the project configuration.

## Rationale

Plain text keeps project data readable, diffable, and version-controlled.

## Verification Method

Inspect the files Papyrus writes; confirm that managed records are UTF-8 Markdown (HTML for UI mockups), the configuration is UTF-8 YAML, and no file contains binary data.
