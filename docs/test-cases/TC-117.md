# TC-117 An unresolvable selector is rejected with its selector path

## Description
## Scenario: An unresolvable selector is rejected with its selector path

GIVEN a configuration whose req member fields are story and description
WHEN a contributor reads the selector document_types.req.member.fields[unknown].heading
  AND reads the selector document_types.req.group.fields[9].required
THEN each read is rejected with one validation outcome and exit code 4
  AND each diagnostic names the selector path that did not resolve
  AND no value is printed
