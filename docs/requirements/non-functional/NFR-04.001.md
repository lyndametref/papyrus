# NFR-04.001 Persist Application Data Only in Text Files

## Description
All data saved by Papyrus shall be stored in text files only.

## Rationale
This records the requirement that all saved data use text files without adding a particular text-file format.

## Verification Method
Review Papyrus's saved artifacts and storage mechanisms to confirm that all saved data is stored in text files only.

## Open Questions
The precise boundary of “all data saved by Papyrus” and what qualifies as a text file have not been specified.
