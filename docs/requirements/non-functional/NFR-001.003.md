# NFR-001.003 Offline Browser Operation

## Description

The `papyrus-browser` binary and the local browser interface shall operate without an internet connection.

## Rationale

The interface is served locally and must stay usable on isolated machines.

## Verification Method

With external networking disabled and loopback available, invoke the `papyrus-browser` binary, exercise list, view, and edit across record types, and confirm that the interface remains usable and that no outbound network request is attempted.
