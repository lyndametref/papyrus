# GLO-013 Seed

## Definition
The built-in list of default record types offered at initialization, defined by one configuration file in the source tree that is compiled into the shared core library at build time. It has two families: the `document_types` map, which lists document types with their model, field sequence, prefix, folder, custom status set, slots, and field defaults, and the `decision_types` map, which lists decision types with their prefix, folder, and the shared status vocabulary.

Also known as: seed configuration, seed entry, document-type seed, decision-type seed.

Related terms: Document Type, Record Type, Decision Type, Grouped Record, Formatted Record.
