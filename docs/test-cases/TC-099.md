# TC-099 Setting a declared custom status changes only the status and refreshes updated_date

## Description
## Scenario: Setting a declared custom status changes only the status and refreshes updated_date

GIVEN an active document record whose status is active
  AND the record's type declares the custom status review
  AND the record has an earlier updated_date
WHEN a contributor runs the document status command for that record with review
THEN the record's front-matter status is review
  AND the record's updated_date is later than before
  AND the record's title, body, labels, and references are unchanged
  AND the file remains in the type's active folder
