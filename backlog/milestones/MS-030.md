## Description
Enhancement from RE-008. AC-1 milestones inside each release ordered by the lowest ordinal among their non-archived tasks ascending, so the milestone containing the lowest-ordinal task appears first; milestones with no non-archived task after all others, by milestone ID ascending; ties by milestone ID ascending. AC-2 the no-release group follows the same rule. AC-3 releases ordered by the lowest ordinal among the non-archived tasks in their milestones ascending; releases with no such task after all others, by release ID ascending; ties by release ID ascending. AC-4 every displayed open milestone shows an open marker immediately before its title; every displayed closed milestone shows a closed marker. AC-5 every displayed planned release shows an open marker; every displayed released release shows a closed marker. AC-6 archived milestones are not displayed. AC-7 each displayed closed milestone shows a cleanup control immediately after its title. AC-8 each displayed released release containing at least one closed milestone shows a cleanup control immediately after its title. AC-9 a released release with no closed milestone shows no cleanup control. AC-10 activating a milestone cleanup control shows a confirmation listing the milestone ID; confirming archives it and removes it from the view; cancelling archives nothing. AC-11 activating a release cleanup control shows a confirmation listing the IDs of closed milestones in that release; confirming archives each listed milestone; the release remains visible and released. AC-12 a release cleanup never archives the release itself. AC-13 if archiving one milestone fails, the failure is reported, remaining milestones are still archived, and the failed milestone stays visible. AC-14 controls are browser-only and add no CLI command. AC-15 milestone and release lifecycle rules are unchanged. AC-16 UI-002 is revised to replace ascending milestone and release ID ordering with ascending lowest-contained-task-ordinal ordering and to document markers and cleanup controls. AC-17 MOCK-0002 and MOCK-0017 are the affected mockups; MOCK-0016 is not impacted because the Backlog board scope does not change the browser shell or the flat list layout.
