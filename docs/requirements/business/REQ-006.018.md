# REQ-006.018 Remove Configuration, Managed Artifacts, and Agent Skills Sections from the Browser

## User Story

As a project contributor, I want the browser navigation and routes for Configuration, Managed artifacts and lifecycles, and Agent skills and workflows removed so the browser interface stays focused.

## Group

REQ-006 Search and Local Web Interface

## Criticality

Should have

## Description

The browser no longer serves or links to the Configuration, Managed artifacts and lifecycles, or Agent skills and workflows sections. Their navigation entries and underlying routes are removed. Configuration editing remains available through the CLI (`papyrus config`), and managed-artifact and skill documentation remains available outside the browser. The removal applies to all browser views and does not change the underlying records or configuration files.

## Acceptance Criteria

- The browser navigation contains no entry for Configuration, Managed artifacts and lifecycles, or Agent skills and workflows.
- The underlying routes for those three sections are removed and are not reachable.
- Configuration editing remains available through the CLI.
- Managed-artifact and skill documentation remains available outside the browser.
- The removal does not change underlying records or configuration files.
- Other browser pages and navigation continue to work.
