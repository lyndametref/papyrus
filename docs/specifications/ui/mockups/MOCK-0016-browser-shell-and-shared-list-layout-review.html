Web prototype

Milestone list in the shell with the seven-column shared table, Title-cell tag line and row actions; the record view and edit form inside the same shell as unchanged context; the empty state; the 320 px treatment.

Open web prototype

What to review

  • Shell. One header, one navigation, one main region, one footer per page. Brand, project name, offline note and footer copy are unchanged; the navigation toggle belongs to TASK-144 and is not drawn.
  • Shared table. Seven columns in the fixed order; scope="col" on every header cell; one row per record; the table carries data-list-layout="shared", data-column per header cell and data-row-id per row.
  • Title cell. The record title is the link; labels and references sit on a second line inside the same cell.
  • Action cell. Last column, View then Edit, each with an accessible name that names the record.
  • Width. Capped only, rendered as class="app"; no app--full surface exists in this ticket. No client-side width switching.
  • Narrow. Seven columns at 320 CSS px scroll inside the table region; the page itself gains no horizontal scrollbar.
