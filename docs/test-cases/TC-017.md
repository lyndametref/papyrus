# TC-017 Milestone archive on an already archived milestone is a no-op success

## Description
## Scenario: Milestone archive on an already archived milestone is a no-op success

GIVEN an initialized Papyrus project with an archived milestone MS-003
WHEN the user runs `papyrus milestone archive MS-003`
THEN the command exits 0 and prints the milestone ID
  AND no file is written or moved
  AND the milestone remains archived
