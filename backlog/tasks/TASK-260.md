## Description
## Context
Help is now derived from the descriptor and field sequence, so the MS-032 `tests/golden/cli-help/*.json` snapshots will change in known ways; anything else is a regression. The golden harness is `tests/cli_help_golden.rs` (`PAPYRUS_UPDATE_CLI_HELP=1` regenerates; `golden_snapshot_set_is_complete` rejects stale files). The equivalence corpus is `tests/fixtures/characterization/corpus/cases.json` with expected artifacts under `expected/`, replayed by `tests/characterization_replay.rs`. `tests/fixtures/characterization/corpus/EXPECTED-DELTAS.md` is the recorded delta list. `tests/descriptor_equivalence.rs::cli_help_projection_matches_the_frozen_goldens` also reads the goldens.

## Expected help deltas
| Area | Expected change | Attribution |
|---|---|---|
| Glossary create/edit | `--term` removed; positional `TITLE` added; `--definition` remains; usage and option list change | Uniform title contract and --term removal |
| Audit create | Positional `TITLE` added; `--title` kept | Additive audit positional title |
| Requirement create-group | Positional `TITLE` added; `--title` kept | Additive create-group positional title |
| Requirement create | Optional positional `[title]` becomes the uniform positional `TITLE`; `--title` kept | Uniform title contract |
| Every typed create/edit | Field options derived from the seed field sequence; option help prose from `label`/`help`/kind; `-d` short disappears | Derived field options |
| ui-mockup create/edit | Model-fixed options (`--task`, `--spec`, `--ref`, and the existing edit options) plus the title contract | Model-fixed mockup options |
| Top help | No order change: enabled types stay in effective `document_types` map order (slug order); seed `order` is presentation-only | ADR-042 ruling 4 |
| Verb about lines | Every verb about line is generated by the engine from the document model and field sequence; per-type about text is not preserved | ADR-042 ruling 2; generated help prose |

## Fixture replay deltas
- The two captured `--term` usage-error cases (`glossary/create-term-removed` and `glossary/edit-term-removed`) expect exit 2 and write no record; the four migrated cases (`glossary/create`, `glossary/create-json`, `glossary/edit`, and `glossary/edit-json`) keep exit 0 with the new title form.
- Every other case keeps its record bytes and exit code; stdout differs only where a listed help/option/title delta explains it.
- `EXPECTED-DELTAS.md` item 2 must be corrected: `--term` is removed, `--definition` remains (the current sentence says both are removed).
