# TC-118 An invalid configuration blocks commands except the repair surfaces

## Description
## Scenario: An invalid configuration blocks commands except the repair surfaces

GIVEN a configuration whose glossary entry declares an unknown field kind
WHEN a contributor runs the glossary list command and the task list command
  AND runs config list
  AND runs check
  AND runs init with force
THEN the glossary and task commands each refuse with a validation outcome and exit code 4
  AND config list prints the effective configuration
  AND check reports the configuration findings and still runs the checks that do not need the document-type set
  AND init with force replaces the file with the default configuration
