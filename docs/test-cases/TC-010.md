# TC-010 An HTTPS Origin for an allowed authority is rejected with 403

## Description
## Scenario: An HTTPS Origin for an allowed authority is rejected with 403

GIVEN an initialized Papyrus project with at least one editable record
  AND the browser server running on `127.0.0.1:<port>`
  AND a valid urlencoded edit form body for that record, including its current `version` token
WHEN a browser edit form POST is sent whose `Origin` uses the `https://` scheme for the allowed authority (for example `https://127.0.0.1:<port>`)
THEN the POST returns `403 Forbidden` (not `303`)
  AND the request body is not parsed and no record file is modified
