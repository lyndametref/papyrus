# TC-015 Milestone archive moves an open milestone to the archive folder and keeps its status

## Description
## Scenario: Milestone archive moves an open milestone to the archive folder and keeps its status

GIVEN an initialized Papyrus project with an open milestone MS-001
WHEN the user runs `papyrus milestone archive MS-001`
THEN the status stays `open` and no close step is performed
  AND the file is moved to `backlog/milestones/archive/MS-001.md`, with no separate archived status introduced
  AND `updated_date` is refreshed once
  AND title, description, labels, references, and release assignment are preserved
  AND the command exits 0 and prints the milestone ID
  AND the archived milestone is hidden from active milestone lists
