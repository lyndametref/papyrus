# REQ-005 Project Documentation Management

## User Story

As a project contributor, I want to manage structured project documentation so that requirements, terms, specifications, rules, and audit records are available alongside backlog information.

## Description
This group covers the document artifact category (REQ-007.001): managing the records of the three document models — SingleMarkdown (REQ-005.015), GroupedMarkdown (REQ-005.001), and SingleHtmlMockup (REQ-005.008) — listing and viewing them (REQ-005.017), archiving and deleting them (REQ-005.007), and the YAML front-matter metadata of managed Markdown records (REQ-005.010) together with its automatic maintenance (REQ-005.011). The document types a project configures are offered at init by the Seed (REQ-005.016) and defined by the project configuration (REQ-007.002); the requirements in this group name document models, not individual document types.
