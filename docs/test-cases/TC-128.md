# TC-128 Help output is deterministic and lists configured types in declaration order

## Description
## Scenario: Help output is deterministic and lists configured types in declaration order

GIVEN a fixed effective configuration with the seed document types declared
WHEN a contributor requests the root help twice from different working directories and terminal widths
THEN both outputs are identical
  AND the configured document slugs appear in the order in which the configuration declares them
  AND the output contains no absolute path, host name, timestamp, process identifier, or memory address
