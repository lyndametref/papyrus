# REQ-006.022 Clean Up Closed Milestones and Released Releases in the Browser Backlog

## User Story

As a project maintainer, I want to archive closed items from the Backlog view so that completed groups disappear after their work is delivered.

## Group

REQ-006 Search and Local Web Interface

## Description

The browser Backlog view offers a cleanup control immediately after the title of each closed milestone and each released release that contains at least one closed milestone. Activating the control first shows a confirmation that lists the IDs of the records that will be archived and requires explicit confirmation; cancelling archives nothing. For a closed milestone, confirmation archives that milestone only, using the milestone archive semantics of REQ-003.001: the milestone moves to the archive location and disappears from the Backlog view. For a released release, confirmation archives each closed milestone contained in that release, one by one, and leaves the release itself active and visible; the release is never archived. If archiving one record fails, the action reports the failure for that record, continues with the remaining records, and leaves the failed record visible. The cleanup control is a browser action; it introduces no new CLI command and does not change milestone or release lifecycle rules.

## Acceptance Criteria

- Each displayed closed milestone shows a cleanup control immediately after its title.
- Each displayed released release that contains at least one closed milestone shows a cleanup control immediately after its title.
- A released release with no closed milestone shows no cleanup control.
- Activating a milestone cleanup control shows a confirmation listing the milestone ID that will be archived.
- Confirming archives that milestone and removes it from the Backlog view.
- Cancelling the confirmation archives nothing.
- Activating a release cleanup control shows a confirmation listing the IDs of the closed milestones in that release that will be archived.
- Confirming archives each listed milestone; archived milestones disappear from the view; the release remains visible and released.
- A release cleanup never archives the release itself.
- If archiving one milestone fails, the failure is reported for that milestone, the remaining milestones are still archived, and the failed milestone stays visible.
- The controls are available in the browser only and add no CLI command.
- Milestone and release lifecycle rules are unchanged.
