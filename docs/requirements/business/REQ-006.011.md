# REQ-006.011 Adjust Glossary Landing Page Display

## User Story

As a project contributor, I want the glossary landing page to show labels as tags without dates or references so that it stays concise.

## Group

REQ-006 Search and Local Web Interface

## Criticality

Could have

## Description

The glossary landing page is the one document list with a deliberately reduced row: it shows no created or updated dates and no reference list, and it presents labels as a tag list. The tag list is the presentation defined for labels by the browser UI specification for glossary terms.

The change is limited to the glossary landing page. Glossary single-record views keep the shared layout, and the landing pages of other document types are unchanged.

## Acceptance Criteria

- The glossary landing page omits created and updated dates.
- The glossary landing page shows labels as a tag list.
- The glossary landing page shows no reference list.
- Glossary single-record views are unchanged by this requirement.
- The landing pages of other document types are unchanged.
