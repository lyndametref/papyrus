# TC-003 Tasks with @-prefixed assignees parse and retain full metadata

## Description
## Scenario: Tasks with @-prefixed assignees parse and retain full metadata

GIVEN task files exist under `backlog/tasks/` with `@`-prefixed assignee entries in their front matter (for example TASK-144 and TASK-145)
WHEN the user runs `papyrus task view <task-id>` for each affected task
  AND runs `papyrus task list`
THEN the files parse without falling back to default values
  AND `task view` reports `title`, `status`, `assignee`, `milestone`, labels, and dependencies for each task
  AND `task list` shows each task's real title rather than its ID
