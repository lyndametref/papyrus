# REQ-03 Milestone and Release Planning

## User Story
As a project maintainer, I want to group work into milestones and releases so that planned delivery can be organized and reviewed.

## Description
This group covers the milestone and release record types of the backlog artifact category (REQ-07.001): creating, viewing, listing, and editing them, the documented relationship between them, and their fixed lifecycles. Their lifecycles are not configurable; only task statuses are configurable in the backlog category.
