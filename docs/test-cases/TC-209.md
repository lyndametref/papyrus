# TC-209 The source tree is a three-crate Cargo workspace under apps/

## Description
## Scenario: The source tree is a three-crate Cargo workspace under apps/

GIVEN the repository
WHEN the source tree and workspace manifests are inspected
THEN the application is implemented in Rust as the crates `papyrus-core`, `papyrus-cli`, and `papyrus-browser` under `apps/`
  AND `papyrus-cli` and `papyrus-browser` each depend on `papyrus-core` only
  AND no `Cargo.toml`, `src/`, or `target/` exists at the repository root
  AND `cargo build`/`test`/`fmt`/`clippy` run from `apps/`
