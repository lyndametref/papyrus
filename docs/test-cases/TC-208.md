# TC-208 Search matches across categories, honours filters, and includes archived records only on request

## Description
## Scenario: Search matches across categories, honours filters, and includes archived records only on request

GIVEN records across backlog, decision, and document categories, including an archived record
WHEN the user runs `papyrus search <QUERY>` with and without `--type` and `--limit`
THEN the default search covers every managed record type and excludes archived records
  AND `--type` restricts the results to the selected types and an unknown type is rejected
  AND `--limit` caps the results
  AND `--include-archive` returns the archived record with its archived state shown
  AND the search needs no network access and honours `--json`
