# REQ-001.003 Select Project and Configuration Context

## User Story

As a user managing project data, I want to select the project directory and configuration file so that commands operate using the intended project settings.

## Group

REQ-001 Project Setup and CLI Access

## Criticality

Must have

## Description

Papyrus selects a project directory from `--dir`, `PAPYRUS_DIR`, or the current working directory, in that order. It selects a configuration file from `--config`, `PAPYRUS_CONFIG`, or the selected project directory's `papyrus.config.yml`, in that order. The selected configuration path must resolve inside the selected project directory; a path outside it is rejected. If none of these yields an existing configuration file, every command except `papyrus init` fails: Papyrus does not fall back to built-in defaults, does not walk up parent directories, and does not discover a configuration file elsewhere. The global options `--help` and `--version` are also exempt: they must work without a project configuration. Built-in defaults apply only to individual keys absent from a configuration file that was found. A command-line option takes precedence over the corresponding environment variable, configuration value, and default.

## Acceptance Criteria

- With no project-directory override, commands use the current working directory.
- `PAPYRUS_DIR` selects the default project directory, and `--dir` overrides it.
- The configuration file is selected from `--config`, then `PAPYRUS_CONFIG`, then the project directory's `papyrus.config.yml`.
- The selected configuration path resolves inside the project directory; a `--config` or `PAPYRUS_CONFIG` path outside it is rejected.
- If none of those paths exists, every command except `papyrus init` fails, with no built-in-defaults fallback and no directory walk-up or discovery.
- The global options `--help` and `--version` work without an existing configuration file.
- An explicitly named `--config` or `PAPYRUS_CONFIG` path that does not exist counts as not found and fails the same way.
- The failure is a runtime error (REQ-001.004) whose message names the searched path and states that `papyrus init` creates the configuration.
- `papyrus init` runs without an existing configuration file.
- Built-in defaults apply only to individual keys absent from a configuration file that was found.
- A command-line option takes precedence over the corresponding environment variable, configuration value, and default.
