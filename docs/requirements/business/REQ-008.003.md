# REQ-008.003 Provide the Help Command

## User Story

As a Papyrus user, I want one command that shows the full manual or a single command's help so that I do not have to remember which help surface to use.

## Group

REQ-008 User Documentation

## Criticality

Should have

## Description

`papyrus help` prints the Papyrus manual — the same content as `man papyrus` (REQ-008.001). `papyrus help <COMMAND>` prints the help of that command, the same content as `papyrus <COMMAND> --help` (REQ-008.002). A command named by `help` that does not exist is a usage error (REQ-001.004) and names the unknown command.

The output is human-readable text that may use ANSI styling; the global `--no-color` option and the `NO_COLOR` environment variable disable the styling, and the content stays readable without it. Both forms require no record read and write nothing. Both forms exit successfully when they print help.

## Acceptance Criteria

- `papyrus help` prints the Papyrus manual, with the same content as `man papyrus`.
- `papyrus help <COMMAND>` prints that command's help, with the same content as `papyrus <COMMAND> --help`.
- `papyrus help <COMMAND>` for an unknown command is a usage error that names the unknown command.
- `papyrus help` and `papyrus help <COMMAND>` read no record and write nothing.
- The output is human-readable text, may use ANSI styling, and `--no-color` disables the styling while the content stays readable.
- Both forms exit successfully when they print help.
