# TC-167 Visible types render list references and every type keeps them in the detail view

## Description
## Scenario: Visible types render list references and every type keeps them in the detail view

GIVEN a ui-spec record and a user-defined deploy record that both carry references
WHEN a contributor opens each type's list and the record detail view in the browser
THEN each list row renders its reference list
  AND each detail view shows a References disclosure containing the references
  AND the CLI view and JSON output still show the same references
