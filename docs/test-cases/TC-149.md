# TC-149 Archiving a record keeps its custom status value

## Description
## Scenario: Archiving a record keeps its custom status value

GIVEN a glossary record whose status is review
WHEN a contributor archives that record
THEN the record's status is still review
  AND the archived file keeps the status value review in its front matter
  AND the record's file is in the archive subfolder of the type's directory
