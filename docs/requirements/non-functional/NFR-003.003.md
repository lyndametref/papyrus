# NFR-003.003 Packaged Man Pages

## Group

NFR-003 Implementation and Distribution

## Description

Papyrus shall ship man pages, and the Debian packages shall install them. The papyrus package installs papyrus(1) and papyrus-config(5); the papyrus-browser package installs papyrus-browser(1).

The pages document every built-in command exactly. Record-type commands are not documented per type, because document types and decision types are declared in the configuration and cannot be enumerated when the package is built. Instead, the manual contains one section per configured family — document types and decision types — written against the `<slug>` placeholder, for example `papyrus <slug> create`, and that section explains how a slug is configured: that the slug is both the configuration key and the command name, which configuration map declares it (`document_types` or `decision_types`), which entry keys apply to it, and that the type's own `--help` lists the options generated from its configuration entry.

Man page sources shall be Markdown files under `docs/man/`, generated to roff at build time, and installed to the standard man paths in the `.deb`.

## Rationale

The requested packaging requirement makes the man page mandatory rather than optional or deferred, and requires each command to be documented. A static page cannot list a command that is created at run time from the configuration, so the manual documents the `<slug>` family and points to the configuration and the generated help; that keeps the package buildable without knowing a project's types while still telling a reader how to obtain and configure one. The Markdown sources also serve as development input and are intended to be reusable with minimal improvements.

## Verification Method

Inspect the Debian package contents to confirm that man pages are installed under the standard man paths and generated from the Markdown sources under `docs/man/`; that every built-in command appears; that the document-type and decision-type sections use the `<slug>` placeholder and explain how a slug is configured (the configuration map, the entry keys, and the generated `--help`); that no per-type man page is expected; and that each documented behaviour matches the page.
