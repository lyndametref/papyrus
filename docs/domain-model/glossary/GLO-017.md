# GLO-017 SingleHtmlMockup

## Definition
The document model whose records have an HTML body, a plain identifier, no field sequence, and fixed metadata states in the HTML metadata comment instead of front matter. The states are pending, approved, and archived.

Also known as: HTML mockup model.

Related terms: Document Model, Role.
