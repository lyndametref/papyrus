# NFR-004.005 Record-Only Persistence

## Description

Papyrus shall persist application state only in managed record files and the project configuration file. It shall create no database, index, cache, lock file, sidecar, or mapping store. Output that a command is explicitly asked to produce is not application state.

## Rationale

A closed store set keeps the project self-contained and reviewable; state hidden in separate stores drifts from the records.

## Verification Method

Run the commands that write records and configuration while monitoring the files created in the project; confirm that the only persistent files are managed record files and the project configuration file, that no database, index, cache, lock file, sidecar, or mapping store appears, and that a temporary file used for an atomic write is removed when the command completes.
