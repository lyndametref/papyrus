## Scenario
A POST whose `Origin` host is a different member of the allowed host set than the `Host` header (for example `localhost` vs `127.0.0.1`) is accepted, because origin validation checks membership in the allowed host set rather than exact equality with the request host.

## Preconditions
- An initialized Papyrus project with at least one editable record.
- The browser server running on `127.0.0.1:<port>`.
- A valid urlencoded edit form body for that record, including its current `version` token.

## Steps
1. Render the edit form for an existing record and capture its `version` token.
2. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, `Origin: http://localhost:<port>`, `Content-Type: application/x-www-form-urlencoded`, and the valid form body.
3. Repeat with `Host: 127.0.0.1:<port>` and `Origin: http://[::1]:<port>`.

## Expected outcome
- Both POSTs return `303 See Other` (not `403`).
- The edits are persisted.
