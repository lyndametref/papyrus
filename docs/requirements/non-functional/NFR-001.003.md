# NFR-001.003 Use the Browser Command and Interface Without Internet

## Group

NFR-001 Product Form

## Description

The `browser` command and local browser interface shall be usable without an internet connection.

## Rationale

This records the requirement that both the command and the locally served interface work without internet access.

## Verification Method

Disconnect internet access, invoke the `browser` command, and verify that the local browser interface starts and remains usable.
