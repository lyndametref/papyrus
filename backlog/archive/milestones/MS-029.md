## Description
Bug batch for RE-007: create and update commands reject multiline field values because single-line sanitization rejects embedded newlines. Resolved scope: multiline text arrives on stdin and applies only to body and content fields; identifiers and titles stay single-line. Acceptance criteria: AC-1 document-type create and update commands accept multiline body and content text (for example description, decision, context, consequences) from stdin; AC-2 backlog task and milestone create and update commands accept multiline description text from stdin; AC-3 identifiers, titles, and other single-line fields still reject embedded newlines; AC-4 existing single-line argument and editor paths behave unchanged; AC-5 automated regression tests cover accepted stdin multiline body and content fields and rejected multiline identifiers and titles; AC-6 CLI help documents the stdin multiline input path.
