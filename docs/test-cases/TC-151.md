# TC-151 Archiving or deleting a requirement group leaves every member unchanged

## Description
## Scenario: Archiving or deleting a requirement group leaves every member unchanged

GIVEN a requirement group REQ-006 with two active members
WHEN a contributor archives the group
  AND deletes another requirement group that also has members
THEN each member keeps its file, its status active, and its ID
  AND each member's group key is unchanged
  AND each member is still listed under its group
