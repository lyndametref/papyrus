## Scenario
A POST with no `Origin` header is not rejected by origin validation (non-browser or same-origin clients that omit it), so the request proceeds to normal handling.

## Preconditions
- An initialized Papyrus project with at least one editable record.
- The browser server running on `127.0.0.1:<port>`.
- A valid urlencoded edit form body for that record, including its current `version` token.

## Steps
1. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, no `Origin` header, `Content-Type: application/x-www-form-urlencoded`, and the valid form body.

## Expected outcome
- The POST returns `303 See Other` (not `403`).
- The edit is persisted.
