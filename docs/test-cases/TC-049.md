# TC-049 Titles containing embedded newlines are rejected

## Description
## Scenario: Titles containing embedded newlines are rejected

GIVEN a Papyrus project that enables the request document type and has a backlog
  AND no record exists for the attempted titles
WHEN the user runs the request document create command with a title containing an embedded newline
  AND the user runs the task create command with a title containing an embedded newline
THEN both commands exit with the validation outcome exit code 4
  AND neither command creates a record
