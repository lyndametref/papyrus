# RE-002 Milestone command must support archiving milestones

## Description
Context: During cleanup, `papyrus milestone` exposes only `close`, which changes status to `closed` but does not move the milestone file to the archive location. The user expected an archive operation equivalent to `backlog milestone archive`, moving the milestone to `backlog/archive/milestones/`.

Requested outcome: Add an `archive` (or equivalent) command to `papyrus milestone` that moves the milestone record to the archive location and marks it archived, so milestones are removed from active listings without manual file operations.

## Items

### Item 1
- Statement: The milestone command must allow archiving milestones, moving them to the appropriate archive subfolder instead of only changing status.
