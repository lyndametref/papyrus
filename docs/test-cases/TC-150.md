# TC-150 Deleting an active record archives it first and requires confirmation

## Description
## Scenario: Deleting an active record archives it first and requires confirmation

GIVEN an active use-case record UC-005
WHEN a contributor deletes that record without force and cancels the confirmation
  AND deletes it again without force and confirms
THEN the cancelled run leaves the record active and unchanged
  AND the confirmed run removes the record file permanently
  AND deleting with force skips the confirmation prompt
