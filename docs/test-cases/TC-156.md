# TC-156 A tech-spec create with one optional description stores it in the body

## Description
## Scenario: A tech-spec create with one optional description stores it in the body

GIVEN a project whose configuration enables the tech-spec type
WHEN a contributor creates a technical specification titled Storage layout
  AND creates a second one with a description supplied on standard input
THEN the first record is valid with only a title
  AND the second record holds the description under the Description section
  AND neither record carries a front-matter key for description
