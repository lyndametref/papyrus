## Scenario: Collapsible sections are omitted for empty collections

GIVEN a record whose references, dependencies, and dependents are all empty
WHEN the user opens the record's single view
THEN no references collapsible section is shown
  AND no dependencies collapsible section is shown
  AND no dependents collapsible section is shown
