# TC-200 Project and configuration context resolution and the missing-configuration failure

## Description
## Scenario: Project and configuration context resolution and the missing-configuration failure

GIVEN a directory with `PAPYRUS_DIR` unset and a configuration only under the selected project directory
WHEN the user runs a command with `--dir` and with `PAPYRUS_DIR`
THEN `--dir` overrides `PAPYRUS_DIR`, and the working directory is used when neither is given
  AND a `--config` path outside the project directory is rejected
GIVEN no existing configuration file at any searched location
WHEN the user runs a command other than `init`
THEN the command fails with a runtime error and exit code 1
  AND the message names the searched path and states that `papyrus init` creates the configuration
  AND `--help` and `--version` still work
