# GLO-016 Grouped Record

## Definition
The record model in which records form groups: a group record with a plain identifier and member records with dotted identifiers, each carrying a Markdown body and its own role field set.

Also known as: grouped Markdown model.

Current model value: `grouped-record`. Former name: GroupedMarkdown.

Related terms: Document Type, Group Record, Member Record, Role, Field Specification.
