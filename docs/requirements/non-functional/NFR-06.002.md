# NFR-06.002 Use Open-Source Dependencies That Permit GPLv3-or-Later Linking

## Description
Papyrus shall use only open-source runtime dependencies with licenses that do not prevent linking those dependencies in a GPLv3-or-later application. "Open-source" means OSI-approved licenses; "linking" means dynamic or static linking under GPLv3-or-later.

## Rationale
This records the requested open-source and linking-license constraints for dependencies used by Papyrus.

## Verification Method
Review the runtime dependency inventory and each dependency's license to confirm that every dependency is open source (OSI-approved license) and its license does not prevent dynamic or static linking in a GPLv3-or-later application.
