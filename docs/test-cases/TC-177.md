## Scenario: check exits 4 on findings and 0 on a clean run

GIVEN a corpus with no duplicate IDs, no dangling references, no dependency cycle, no front-matter conflict, and a valid configuration
WHEN a contributor runs check
  AND runs check again after a self-referential task dependency is introduced
  AND runs check with the force flag but without the fix flag
THEN the clean run prints no finding and exits 0
  AND the second run reports the self-dependency and exits 4
  AND the force-only invocation is a usage error with exit code 2
