# TC-115 config set refuses a value that makes the configuration invalid

## Description
## Scenario: config set refuses a value that makes the configuration invalid

GIVEN a valid configuration whose glossary entry declares the statuses draft and review
WHEN a contributor sets document_types.glossary.statuses to draft,archived
THEN the command refuses the change with one validation outcome and exit code 4
  AND the diagnostic names document_types.glossary.statuses and states that archived may not be declared
  AND the configuration file is unchanged
