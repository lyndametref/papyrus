# TC-050 Identifiers containing embedded newlines are rejected

## Description
## Scenario: Identifiers containing embedded newlines are rejected

GIVEN an existing task and an existing request record
WHEN the user runs the task edit command with an identifier containing an embedded newline
  AND the user runs the request document view command with an identifier containing an embedded newline
THEN both commands exit with the validation outcome exit code 4
  AND the task and the request record are unchanged
