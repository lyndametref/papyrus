# TC-067 Milestones in the no-release group are ordered by lowest contained task ordinal ascending

## Description
## Scenario: Milestones in the no-release group are ordered by lowest contained task ordinal ascending

GIVEN the no-release group contains milestones MS-003 and MS-004
  AND MS-003 has non-archived task TASK-003 with ordinal 30
  AND MS-004 has non-archived task TASK-004 with ordinal 5
WHEN a contributor opens the Backlog view
THEN MS-004 appears before MS-003 in the no-release group
  AND the no-release group appears before the first release group
