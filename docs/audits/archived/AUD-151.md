# Code audit REL-001 release

- Type: code

## Checks run

- cargo test with the ambient environment failed only the pre-existing editor-environment test; with EDITOR and VISUAL unset it failed the D-06 documentation guard.
- build_package_guard repeated 15 times: 14 passed, 1 failed with ExecutableFileBusy.
- clippy -D warnings clean; fmt clean; release binary 8,245,400 B; 36 packages.

## Findings

### Blocker

B1 archive relocation overwrites an existing archived record: archive_inner, relocate_if_archived, archive_content and the mockup writer do not check the destination before write_atomic. Reproduction: an active record plus a pre-existing archived file of the same ID; archive exits 0 and replaces the archived bytes. Correction: refuse when the destination exists and differs from the source, name the destination, leave both files untouched, add regression tests for all four paths.

### High

H1 the release test suite is not green: the D-06 guard counts the upgrade-notes migration table as a static command inventory. Correction: narrow the guard or rewrite the table, rerun.
H2 a valid field key can collide with generated clap argument ids and panic (title_flag; tags plus no_tags). Correction: namespace generated argument ids or validate every generated id against the fixed engine arguments, with tests.
H3 id reservation loops forever when a directory has a record-like name (GLO-001.md directory). Correction: treat any occupied candidate as a conflict and advance, or bound attempts with an error; add directory and mockup coverage.
H4 mockup refs are written raw into an HTML comment and accept angle brackets and double dash. Correction: encode with the shared comment encoder or reject those characters, add an injection round-trip test.

### Medium

M1 CLI create and edit ignore the declared field value domain (audit-type bogus accepted). Correction: shared domain validation on both surfaces with CLI tests.
M2 mockup saves re-read the record with unwrap_or_default and can write content derived from an empty string. Correction: use the stored source or fail closed with no write.
M3 config set relocates folders before persisting the config and config writes are non-atomic. Correction: atomic config write and ordered or rolled-back relocation; propagate the old-config load error.
M4 the editor test depends on the ambient EDITOR. Correction: clear the variables in the child environment.
M5 the packaged-script guard test is flaky with ExecutableFileBusy. Correction: execute through bash or ensure the handle is closed.

### Low

L1 production relocation honours test-injection environment variables; gate behind cfg(test).
L2 dead code and stale registry documentation remain.

## Invariants checked

No production document slug dispatch remains; the engine builds PatchOps and the single writer stores them; audited unwrap and index sites are guarded apart from H2 and H3. Guards include planted-violation assertions.

## Verdict

corrections required - B1 blocks data integrity, H1 blocks a green gate, H2 and H3 block fail-closed configuration and create availability, H4 blocks browser escaping, and M1 to M5 block the domain, write-safety and reproducible-evidence criteria.
