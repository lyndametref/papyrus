# TC-101 The status verb rejects an archived record and changes nothing

## Description
## Scenario: The status verb rejects an archived record and changes nothing

GIVEN a document record that is archived in the type's archived subfolder
WHEN a contributor runs the document status command for that record with active
THEN the command reports one validation outcome and exits with code 4
  AND the outcome names the record as archived
  AND the record's status is still archived
  AND the file remains in the archived subfolder
