## Scenario: Browser navigation has no entries for removed sections

GIVEN the browser is opened for a project
WHEN the user views the browser navigation
THEN the navigation contains no entry for Configuration
  AND the navigation contains no entry for Managed artifacts and lifecycles
  AND the navigation contains no entry for Agent skills and workflows
  AND the remaining navigation entries are present and usable
