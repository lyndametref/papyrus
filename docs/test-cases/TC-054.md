## Scenario: CLI help documents the multiline standard-input path

GIVEN a Papyrus project that exposes document, task, milestone, and decision commands
WHEN the user requests help for the create and edit commands of a document type, a task, a milestone, and a decision
THEN each help text describes that multiline text can be supplied on standard input
  AND each help text identifies the fields that accept multiline input
