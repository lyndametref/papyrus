# REQ-001 Project Setup and CLI Access

## User Story

As a project maintainer, I want to initialize and configure Papyrus projects from its CLI so that I can manage project data in the intended project context.

## Description

This group covers project initialization, configuration access, directory selection, record identification, common command-line controls and outcomes, and project diagnostics described by the Papyrus man page.
