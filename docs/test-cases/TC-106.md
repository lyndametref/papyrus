# TC-106 A duplicate field key within a role is rejected

## Description
## Scenario: A duplicate field key within a role is rejected

GIVEN a user-defined type whose fields sequence declares the key description twice
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names the duplicated field key and its location
  AND no record of that type is written
