# TC-199 init creates the stores and configuration, and refuses an existing configuration without --force

## Description
## Scenario: init creates the stores and configuration, and refuses an existing configuration without --force

GIVEN an empty target directory
WHEN the user runs `papyrus init NAME`
THEN the command creates the backlog store, the documentation structure, and `papyrus.config.yml`
  AND the generated configuration validates successfully
WHEN the user runs `papyrus init NAME` again in the same directory
THEN the command fails with a conflict outcome and writes nothing
  AND with `--force` the configuration is replaced completely
