# TC-015 Milestone archive transitions an open milestone to archived

## Description
## Scenario: Milestone archive transitions an open milestone to archived

GIVEN an initialized Papyrus project with an open milestone MS-001
WHEN the user runs `papyrus milestone archive MS-001`
THEN the milestone's status becomes `archived`
  AND the milestone is closed first and then archived
  AND `updated_date` is refreshed once
  AND title, description, labels, references, and release assignment are preserved
  AND the file is moved to `backlog/archive/milestones/MS-001.md`
  AND the command exits 0 and prints the milestone ID
