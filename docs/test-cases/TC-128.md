# TC-128 Help output is deterministic and lists enabled types in seed order

## Description
## Scenario: Help output is deterministic and lists enabled types in seed order

GIVEN a fixed effective configuration with the seed document types enabled
WHEN a contributor requests the root help twice from different working directories and terminal widths
THEN both outputs are identical
  AND the enabled document slugs appear in seed order with slug order breaking ties
  AND the output contains no absolute path, host name, timestamp, process identifier, or memory address
