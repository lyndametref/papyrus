# TC-122 Field options follow the declared names, kinds, and sequence order

## Description
## Scenario: Field options follow the declared names, kinds, and sequence order

GIVEN a project whose configuration enables the rule type with its seed field sequence
WHEN a contributor requests help for the rule create command
THEN the field options appear as description, rationale, applicability, and requirement in that order
  AND each option shows the field label and help text from the descriptor
  AND requirement is shown as repeatable while description is shown as a single value
