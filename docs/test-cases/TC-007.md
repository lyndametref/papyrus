## Scenario
A browser edit form POST whose `Origin` exactly matches the request URL (same scheme, host, and port) passes origin validation and the edit is saved.

## Preconditions
- An initialized Papyrus project with at least one editable record.
- The browser server running on `127.0.0.1:<port>`.
- A valid urlencoded edit form body for that record, including its current `version` token.
- A raw HTTP client able to set `Host` and `Origin`.

## Steps
1. Render the edit form for an existing record and capture its `version` token.
2. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, `Origin: http://127.0.0.1:<port>`, `Content-Type: application/x-www-form-urlencoded`, and the valid form body.
3. Follow the redirect and render the record view.

## Expected outcome
- The POST returns `303 See Other` (not `403`).
- The record view shows the edited values.
- The underlying record file contains the edited values.
