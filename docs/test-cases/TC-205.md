# TC-205 Browser views render math and mermaid diagrams offline and fall back to source

## Description
## Scenario: Browser views render math and mermaid diagrams offline and fall back to source

GIVEN record prose fields containing `$$…$$` math, `$…$` math, `math`/`tex`/`latex` fences, a `mermaid` fence, a `plantuml` fence, and an unclosed delimiter
WHEN the record view is rendered in the browser with networking disabled
THEN display and inline math and mermaid diagrams render from bundled assets with no network request
  AND the plantuml fence and any unrenderable input fall back to source text with a note
  AND CLI output and other surfaces show the source text unchanged
