# TC-159 A write refreshes updated_date and preserves created_date and untouched keys

## Description
## Scenario: A write refreshes updated_date and preserves created_date and untouched keys

GIVEN a glossary record with a created_date, labels, references, and an undeclared front-matter key owner
WHEN a contributor edits the record's definition
THEN updated_date is later than before
  AND created_date is unchanged
  AND the labels, references, and the undeclared owner key are preserved as stored
