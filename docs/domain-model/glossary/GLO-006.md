# GLO-006 Milestone


## Definition
A grouping for tasks that may be assigned to zero or one release; its lifecycle is open -> closed -> archived. `papyrus milestone close` closes it; `papyrus milestone archive` closes it if needed then moves it to the backlog archive milestones directory (REQ-03.001, RE-002).
