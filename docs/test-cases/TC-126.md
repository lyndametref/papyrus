# TC-126 A create without a title is rejected

## Description
## Scenario: A create without a title is rejected

GIVEN a project whose configuration enables the tech-spec type
WHEN a contributor creates a technical specification with no positional title and no title option
THEN the create reports one validation outcome and exit code 4
  AND the outcome names the missing title
  AND no technical specification is written
