## Description

Implementation and specification work that extends Release 1.0 after the architecture decisions ADR-0010 to ADR-0013 and the requirement changes of 2026-11-11: Papyrus-native record layout and single ID space, one-way Backlog.md import, configuration changes, and browser refinements. Kept in a dedicated feature milestone so more requirements can still arrive before 1.0 without changing the definition of the release gate, which stays in m-14.
