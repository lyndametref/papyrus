# TC-192 An unknown, archived, or disabled document address returns the same not-found page

## Description
## Scenario: An unknown, archived, or disabled document address returns the same not-found page

GIVEN an archived document record, an unknown document ID, and a disabled document type
WHEN a contributor requests each of those records in the browser
THEN each response has status 404 and renders the same not-found page
  AND no archived record content or disabled type content is shown
