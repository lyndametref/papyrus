# TC-022 Archived milestone remains viewable and editable in place

## Description
## Scenario: Archived milestone remains viewable and editable in place

GIVEN an initialized Papyrus project with an archived milestone MS-008
WHEN the user runs `papyrus milestone view MS-008`
  AND the user runs `papyrus milestone edit MS-008 --title "New title"`
THEN the milestone is readable by ID
  AND the edit is applied in place
  AND the milestone remains archived
