# NFR-007.003 Browser asset caching contract (versioned immutable vendor assets and validated app assets)

## Group
NFR-007 07 Document Engine Performance

## Description
Browser assets must be served so that repeat visits transfer no vendor bytes and revalidate app assets cheaply:
- Vendor files (Mermaid 3.57 MB, KaTeX 275 KB, fonts) are served from versioned URLs with Cache-Control immutable and a long max-age.
- app.css and app.js are served with Cache-Control no-cache plus an ETag; a conditional request returns 304 with no body.
- HTML and JSON responses stay Cache-Control no-store.
- Assets only: no record response becomes cacheable.
- No compression is introduced.

Measurement method: HTTP header assertions in the integration suite plus a repeat-visit measurement in the MS-032 harness recording bytes transferred on the second load. If the project declines asset caching, this NFR must be replaced by an explicit exclusion decision recorded in ADR-038 instead of being left unmet.
