# TC-005 Regression: import preserves assignee and comparable list fields as valid YAML lists

## Description
## Scenario: Regression: import preserves assignee and comparable list fields as valid YAML lists

GIVEN a source Backlog.md task with multiple assignees (for example `@rust-dev`, `@qa`) and non-empty labels, dependencies, and documentation lists
  AND an initialized Papyrus target project
WHEN the user runs `papyrus import backlog --from <source>`
THEN each list field is serialized as a YAML sequence with one item per line
  AND assignee entries beginning with `@` are quoted
  AND `papyrus task view` reports all assignees and every comparable list field without data loss
