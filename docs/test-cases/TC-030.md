## Description
## Scenario: Single-record layout renders in Firefox 115 without layout breakage

GIVEN Firefox version 115 or later
  AND records of several managed Markdown types
WHEN the user opens each record's single view
THEN each view renders without layout breakage
  AND the interface remains usable
