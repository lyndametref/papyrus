# Technical Specification

## Definition

A documentation type recognized by Papyrus (README DESCRIPTION) describing a technical design or behavior. A task may reference zero or more technical specifications (REQ-02.001), and it may reference non-functional requirements (README line 438 / BR-010); the cardinality of that reference is unspecified. Other attributes, lifecycle, ID format, prefix, storage directory, and command behavior are unspecified (REQ-05.009).
