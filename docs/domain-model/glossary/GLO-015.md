# GLO-015 Record Type

## Definition
A kind of managed record that belongs to exactly one record category. The backlog category contains Task, Milestone, and Release; the decision category contains each configured decision type; the document category contains each configured document type. A record type is a descriptor of a kind of record, not an individual record; a document type is a specialised record type.

Related terms: Record, Record Category, Document Type, Document, Decision Type.
