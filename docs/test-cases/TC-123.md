# TC-123 A field whose verbs exclude edit has no edit option and is never rewritten

## Description
## Scenario: A field whose verbs exclude edit has no edit option and is never rewritten

GIVEN a business rule whose rationale is retained from creation
WHEN a contributor requests help for the rule edit command
  AND attempts to change the rationale through the edit command
THEN the edit help offers no rationale option
  AND the edit attempt is rejected as a usage error with exit code 2
  AND the stored rationale is unchanged
