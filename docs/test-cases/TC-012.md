## Scenario
A POST whose `Origin` host is not a member of the allowed host set is rejected with `403`. This covers a foreign host, a disallowed port, an `Origin` with a path or userinfo component, and an unknown scheme.

## Preconditions
- An initialized Papyrus project with at least one editable record.
- The browser server running on `127.0.0.1:<port>`.
- A valid urlencoded edit form body for that record, including its current `version` token.

## Steps
1. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, `Origin: http://evil.example:<port>`, and the valid form body.
2. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, `Origin: http://127.0.0.1:9999`, and the valid form body.
3. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, `Origin: http://127.0.0.1:<port>/x`, and the valid form body.
4. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, `Origin: ftp://127.0.0.1:<port>`, and the valid form body.

## Expected outcome
- Every POST returns `403 Forbidden`.
- No record file is modified.
