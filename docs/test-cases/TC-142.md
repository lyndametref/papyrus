# TC-142 A rule create stores the three required prose sections in sequence order

## Description
## Scenario: A rule create stores the three required prose sections in sequence order

GIVEN a project whose configuration enables the rule type
WHEN a contributor creates a rule with a title, a description, a rationale, and an applicability
THEN the record body holds Description, Rationale, and Applicability in that order
  AND each value appears under its declared heading
  AND the record has the status active and a RUL prefix
