# TC-063 Glossary landing page display is unchanged

## Description
## Scenario: Glossary landing page display is unchanged

GIVEN glossary terms with definitions, some carrying references
WHEN a reviewer opens the glossary landing page
THEN the page lists the same terms and definitions as before the change
  AND no reference list is added to the page
  AND no term entry changes its displayed fields
