# TC-066 Milestones in a release are ordered by lowest contained task ordinal ascending

## Description
## Scenario: Milestones in a release are ordered by lowest contained task ordinal ascending

GIVEN release REL-A contains milestones MS-001 and MS-002
  AND MS-001 has non-archived task TASK-002 with ordinal 20
  AND MS-002 has non-archived task TASK-001 with ordinal 10
WHEN a contributor opens the Backlog view
THEN MS-002 appears before MS-001 within the REL-A release group
