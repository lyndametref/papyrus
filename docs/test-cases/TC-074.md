# TC-074 Changing a task ordinal and reloading reorders its milestone and release

## Description
## Scenario: Changing a task ordinal and reloading reorders its milestone and release

GIVEN the Backlog view is open with milestone and release positions determined by a task ordinal
WHEN the ordinal of that task is changed and the Backlog view is reloaded
THEN the milestone and its release appear in their new positions according to the updated ordinal
