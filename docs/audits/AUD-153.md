## Findings

### Medium

M-1 a stale executable papyrus_0.1.0_amd64.deb is tracked in the repository root, predating the AUD-151 B1 and H4 fixes; .gitignore does not ignore deb files; builds/0.2.0-rc.1 is a stale verification build. Correction: remove the tracked deb, ignore deb files, discard or mark the stale build, add a guard test. Owner: TASK-288.
M-2 a non-loopback bind has no authentication: the server warns only, the host validator accepts any host, and no session or token exists. Default loopback bind means the risk is opt-in; the approved browser specification permits it with a warning. Correction: explicit network opt-in and/or a per-process bearer token compared in constant time, or a recorded accepted-risk decision. Owner: architect decision plus implementation.

### Low

L-1 Host and Origin validators lack direct tests and a foreign-Host integration case.
L-2 the debug log prints the raw method token, allowing control characters into terminal logs.
L-3 no YAML alias or size budget for config and front matter (hostile-repository denial of service).
L-4 direct build-deb.sh runs can package a stale binary and skip the output emptiness check.
L-5 two move paths use Path::exists() instead of symlink_metadata, weakening the occupied-destination guarantee.
L-6 the config path is read before project-boundary containment (NFR-004.002 ordering); proven with an unreadable outside target.

### Info

No Permissions-Policy header; KaTeX fallback fonts absent; server banner has no version; diagram CSP relaxes style-src only; the concurrency token is mtime plus length by design; cargo audit is not in the toolchain.

## Cross-feature checks

- Configuration plus the single writer: one shared field validator and writer serve CLI, HTML form and JSON, so no path persists a value another rejects.
- Folder relocation plus archive: relocation preflights entries and archive refuses an occupied destination; four regression tests.
- Request snapshot plus writes: writes re-read live bytes and tokens, so stale caches cannot authorise overwrite.
- Mockup metadata: escaped text and encoded comments, so metadata cannot break out of the comment.
- Asset caching: only embedded assets are cacheable; HTML and JSON including errors are no-store.
