## Scenario
Import a Backlog.md task whose `assignee`, `labels`, `dependencies`, and `documentation` fields are non-empty lists, including assignee entries beginning with `@`, and verify that every list field remains a valid YAML list in the imported file and is retrievable.

## Preconditions
- A source Backlog.md task with multiple assignees (for example `@rust-dev`, `@qa`) and non-empty labels, dependencies, and documentation lists.
- An initialized Papyrus target project.

## Steps
1. Run `papyrus import backlog --from <source>`.
2. Read the imported task file.
3. Parse the file with a YAML parser or run `papyrus task view <imported-id>`.

## Expected outcome
- Each list field is serialized as a YAML sequence with one item per line.
- Assignee entries beginning with `@` are quoted.
- `papyrus task view` reports all assignees and every comparable list field without data loss.
