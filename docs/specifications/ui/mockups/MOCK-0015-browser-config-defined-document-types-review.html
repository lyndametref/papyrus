Notes

Notes in this project. Records are read from docs/notes/ and identified by the NOTE prefix.

Apply filter Show all

Filter values are exactly the configured statuses in configured order: active, review, approved. archived is never offered because archived notes are not listed. There is no All option: the disabled Status placeholder is only a prompt, so an untouched submit sends no status parameter and lists every record in the active directory, including records carrying a custom status. Show all is the only reset, and an explicit empty status= is rejected with 400.

Web · Navigation

Sidebar entry for a config-defined type

The sidebar is grouped by artifact category and assembled from the same registry as the views. No separate navigation list exists.

Four groups, in this order

Backlog, Decisions, Documents, Project. Each group label is a small uppercase heading; the entries below it keep their Title Case labels.

  • Backlog: Backlog
  • Decisions: Decisions
  • Documents: Business requirements, Business Rules, Audit Records, Technical Specifications, Use Cases, Test Cases, Test Reports, Non-functional requirements, Glossary, UI Specifications, UI Mockups, then the enabled config-defined types
  • Project: Configuration, Managed artifacts & lifecycles, Agent skills & workflows

All existing entries are kept, with unchanged labels and relative order inside each group. Backlog and Decisions are single-entry groups because each is one unified page.

The enabled config-defined type gets one entry

Notes is added to the Documents group after UI Mockups and before the Project group, using the type's derived label from the slug note. It links to the generic list view. The selected entry uses the same bold/underline and current-page indication as every other entry.

Open the Notes list · Open the lifecycle page

A disabled type has no entry

The disabled Deploy logs example is described on the lifecycle page as enabled: false, but it appears nowhere in this sidebar and has no list, detail, edit, or API response.
