# TC-166 Requirement and nfr list rows render no reference list in either role

## Description
## Scenario: Requirement and nfr list rows render no reference list in either role

GIVEN an active requirement group and member that both carry references
  AND an active non-functional requirement group and member that both carry references
WHEN a contributor opens the req list and the nfr list in the browser
THEN no group row and no member row renders a reference list
  AND no placeholder or expandable control appears in its place
  AND the labels still appear in the title cell
