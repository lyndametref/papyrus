# TC-071 A release with no non-archived task appears after releases with tasks

## Description
## Scenario: A release with no non-archived task appears after releases with tasks

GIVEN release REL-D contains a milestone with non-archived task ordinal 10
  AND release REL-E contains milestones with no non-archived task
WHEN a contributor opens the Backlog view
THEN REL-D appears before REL-E
