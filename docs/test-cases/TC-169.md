# TC-169 A grouped record renders its role fields with a read-only member list

## Description
## Scenario: A grouped record renders its role fields with a read-only member list

GIVEN a requirement group REQ-007 with two members
WHEN a contributor opens the group view and one member view in the browser
THEN the group view shows the group field sections followed by a read-only member list in member ID order
  AND the member view shows the member field sections and a read-only link to its group
  AND neither view offers a membership control or editable group field
