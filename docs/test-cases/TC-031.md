# TC-031 All Papyrus content remains viewable and editable with the uniform layout

## Description
## Scenario: All Papyrus content remains viewable and editable with the uniform layout

GIVEN the uniform single-record layout is in use
  AND records of every Papyrus content type
WHEN the user views and edits a record
THEN the record view displays the content and metadata
  AND edits can be saved and viewed again
