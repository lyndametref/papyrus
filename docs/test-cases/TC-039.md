# TC-039 Other browser pages and navigation continue to work after removal

## Description
## Scenario: Other browser pages and navigation continue to work after removal

GIVEN the browser has the removed sections absent
WHEN the user opens other browser pages and navigates between them
THEN the pages render successfully
  AND navigation between them works
  AND records remain viewable and editable
