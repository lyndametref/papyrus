# REQ-05 Project Documentation Management

## User Story
As a project contributor, I want to manage structured project documentation so that requirements, terms, specifications, rules, and audit records are available alongside backlog information.

## Description
This group covers the documented documentation record types and their create, list, view, edit, deprecate, and restore capabilities, including requirement grouping and type-specific content. Document types include business requirements, non-functional requirements, glossary terms, UI specifications, technical specifications, UI mockups, business rules, audit records, Use Cases, Test Cases, and Test Reports. It also covers the YAML front-matter metadata carried by every managed Markdown record, excluding UI mockup HTML files, and its automatic maintenance by commands.
