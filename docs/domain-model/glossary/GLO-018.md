# GLO-018 Decision Type

## Definition
A configured declaration of a kind of decision record, identified by its slug. A decision type fixes the record's identifier prefix and directory and is declared in the `decision_types` map; presence in the configuration makes the type available. Every configured decision type uses the same fixed decision status vocabulary. A decision type is a record type in the decision record category; a decision record is one instance of it.

Related terms: Decision, Record Type, Record Category, Document Type.
