# TC-058 Generic document single-document view keeps the reference list

## Description

## Scenario: Generic document single-document view keeps the reference list

GIVEN a config-defined document type record that carries two references and labels
WHEN a reviewer opens the single-document view of that record
THEN the collapsible References section is shown with both references
  AND the labels are still shown
  AND the record body and metadata are shown

- Requirement: REQ-06.019
