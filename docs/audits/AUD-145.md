# Code audit MS-035 browser engine

- Audit type: code
- Status: issued

## Scope

Change set 214a252..a90960e plus the TASK-270 verification set: browser mod, records, render, list and routes; record field map and edit; config and registry; the semantic HTML comparator; the characterization corpus; the packaging scripts.

## Checks run

- fmt clean; clippy --all-targets -- -D warnings clean.
- cargo test: 1332 passed, 0 failed, 26 ignored, 68 suites (first run affected only by the ambient EDITOR variable in an unrelated test).
- Semantic baseline: 62 document pages, 268 allowed deltas across 25 forms, 12 sections and 4 mains.
- Mutation probes: a 404 body containing the requested ID, a changed list row, changed edit-form text and a changed title all compared equal, proving the gate cannot fail inside allowlisted containers.
- Packaging: versioned build succeeds and leaves the tree clean; a throwaway repo showed an out-dir inside the repository deletes source files.

## Findings

### High

H1 the semantic equivalence gate hides whole content containers: the allowlist is derived from the page under test and pruned to necessity, so it grows to fit and the unused-entry guard cannot fail; form.form, section.section and main.main hide the list table, the edit and conflict forms and the 404 body. Correction: static per-case node-level allowances, reason validated against EXPECTED-DELTAS, negative tests inside each container.
H2 build-package.sh cleans an arbitrary out directory: an out path inside the repository loses its contents before the build fails. Correction: own a subdirectory, or require empty out, or force flag; refuse paths inside the repo except .tmp, refuse HOME and system dirs, validate before mkdir, add a guard test.

### Medium

M1 HTML and JSON write paths validate differently: HTML accepts invalid requirement references and arbitrary audit types while JSON returns 422; JSON general metadata keys are chosen by sniffing the field-map shape. Correction: declare field domains on the descriptor and use one validator; remove option-string branches and shape sniffing; restore HTML 422 tests.
M2 a field key version collides with the concurrency token and envelope keys; the form then writes the token into the field. Correction: reserve version, kind, form, path and metadata as field keys; add validation and page tests.
M3 no-drift guards pass vacuously and dead document arms remain: the None handler arm still reads description. Correction: delete the dead reads and arms, match fn name regardless of visibility, add structural guards.
M4 reference visibility has two sources with divergent fallbacks and the field-map value is unused. Correction: one descriptor helper, consume or delete the field, test absent role visibility with Hidden descriptor.

### Low

L1 body-then-frontmatter fallback contradicts TECH-040 3.5; amend the spec or remove the fallback.
L2 dead code and duplicated helpers.
L3 mockup references rendered twice, one always empty.
L4 packaging hardening: shared out policy, validate before mkdir, tight version regex.
L5 role and visibility tests do not distinguish behaviour.
L6 copy and documentation defects: conflict sentence, 404 heading order, stale byte-for-byte naming.

Severity counts: blocker 0, high 2, medium 4, low 6.

## Verdict

corrections required - H1 blocks the AC-2 and TC-184 equivalence claim; H2 blocks the AC-9 packaging-safety expectation; M1 to M4 block the AC-5 to AC-7 consistency claims; the rest are quality corrections. Behaviour tests for status codes, mass-assignment rejection, no-op writes, archived and disabled 404 and escaping remain valid.
