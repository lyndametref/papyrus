# NFR-02.001 Treat Security as a Project Priority

## Description
Security shall be treated as a priority when making Papyrus design and review decisions.

## Rationale
This records the requested security focus without prescribing unspecified security standards, controls, or risk targets.

## Verification Method
Review project design and review records to confirm that security is explicitly considered. This verifies the stated priority only; beyond the input-sanitization objective in NFR-02.002, security objectives and measurable acceptance criteria have not been specified.
