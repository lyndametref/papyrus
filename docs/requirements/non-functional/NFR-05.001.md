# NFR-05.001 Display the Browser Interface in Named Browsers

## Description
The Papyrus browser interface shall be supported in Firefox version 100 and later, Microsoft Edge version 100 and later, and Safari version 100 and later.

## Rationale
This records the requested browser families and minimum version without defining visual behavior not supplied in the scope.

## Verification Method
Verify the browser interface using version 100 and later versions of Firefox, Microsoft Edge, and Safari claimed as supported, confirming that the interface is supported in each tested version.

## Open Questions
The meaning of Safari version 100 is unclear; the requirement retains the requested version number without interpreting or substituting it. Criteria for what constitutes browser support beyond displaying the interface are also unspecified.
