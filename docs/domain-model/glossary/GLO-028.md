# GLO-028 Record Model

## Definition
A model that defines a record type's body format, field storage, identifier shape, and state representation. The configured record models are Simple Record, Grouped Record, and Formatted Record; their configuration values remain SingleMarkdown, GroupedMarkdown, and SingleHtmlMockup.

Related terms: Simple Record, Grouped Record, Formatted Record, Record Type, Document Type.
