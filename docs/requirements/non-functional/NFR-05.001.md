# NFR-05.001 Display the Browser Interface in Named Browsers

## Description
The Papyrus browser interface shall be supported in Firefox version 100 and later, Microsoft Edge version 130 and later, and Safari version 18 and later. "Supported" means the interface renders and is usable with no layout breakage in the named browsers.

## Rationale
This records the requested browser families and minimum version without defining visual behavior not supplied in the scope.

## Verification Method
Verify the browser interface using version 100 and later of Firefox, version 130 and later of Microsoft Edge, and version 18 and later of Safari, confirming that the interface renders and is usable with no layout breakage in each tested version.
