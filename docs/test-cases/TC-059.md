# TC-059 CLI list omits references and the CLI view keeps them for generic document types

## Description
## Scenario: CLI list omits references and the CLI view keeps them for generic document types

GIVEN a config-defined document type record that carries references
WHEN the user lists that document type in the CLI
  AND the user views the record in the CLI
THEN the list entry shows only the identifier, the title, and the labels, with no references
  AND the record view shows the record references
