What to review

  • Toggle. Plain text plus a chevron, labelled Navigation, left of the Papyrus mark on every page, 30 px tall (28–32 allowed), 1 px border, soft fill, visible focus ring, aligned with the brand block.
  • Expanded (default). 210 px navigation column, 30 px gap, main column with a left border and 30 px inner padding; page body capped at 1040 px and centred with 24 px padding.
  • Collapsed. Navigation column and gap gone, main left border and padding gone; reclaimed 240 px go to the page body, which keeps the 1040 px cap and its centring. The freed width is never pushed to the window edges as a margin.
  • Full-width page. Cap lifted, 24 px horizontal padding kept, navigation column still 210 px; board columns keep their own minimum widths and the board region scrolls if their sum exceeds the area.
  • Full-window band. Inside a capped page, the band spans the window edge to edge and scrolls its own content; the page never gains a horizontal scrollbar.
  • Narrow widths. At 720 px the two-column layout is kept; at 480 px and 320 px the navigation stacks above the main region and the toggle is the only way to remove it.
  • No JavaScript. The toggle is not drawn, the navigation is expanded and usable.
  • Heading row. At 481–720 px the list heading and count note wrap onto two lines instead of overflowing the page.

Placement and size

Position
Header, immediately left of the Papyrus mark; first control in the header in document order.
Size
30 px tall (28–32 px allowed); width follows the label plus the chevron.
Outline
1 px border, soft fill, slightly rounded corners; plain text plus chevron, no icon artwork.
Focus ring
Visible ring around the whole control, offset from the border, drawn in both states.
Alignment
Vertically centred on the brand block, so the label and the project name share one optical line.
Persistence
Present on every page, including record, edit, error and board pages; it never scrolls away with the page content.

Accessibility annotations

Control
button type="button", not a link.
Expanded
aria-expanded="true"
Collapsed
aria-expanded="false"
Relationship
aria-controls="site-nav" pointing at the navigation region.
Accessible name
“Navigation” in both states, unchanged. State is conveyed by the expanded/collapsed indication, never by renaming the control to “Show”/“Hide”.
Chevron
Decorative; hidden from assistive technology, so it adds no second name.
Keyboard
First tab stop in the header; Enter and Space activate it; the focus ring stays visible after activation.
Collapsed navigation
Removed with the hidden attribute, not merely moved off-screen: it leaves the layout and the accessibility tree and is not reachable by tab.
No script
The markup ships with the toggle hidden; see the No JavaScript view.

Annotation: the state is stored per browser and re-applied before the page paints, so a collapsed page never flashes expanded. The control is on every page because the page body differs while the header does not.
