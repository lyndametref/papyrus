# TC-073 Archived tasks do not contribute to the lowest-ordinal milestone sort key

## Description
## Scenario: Archived tasks do not contribute to the lowest-ordinal milestone sort key

GIVEN milestone MS-009 has only an archived task with ordinal 1
  AND milestone MS-010 has a non-archived task with ordinal 20
WHEN a contributor opens the Backlog view
THEN MS-009 is ordered as a milestone with no non-archived task
  AND MS-009 appears after MS-010
