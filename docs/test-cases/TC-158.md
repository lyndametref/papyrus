# TC-158 A field with both storage locations writes both and a divergence is not merged

## Description
## Scenario: A field with both storage locations writes both and a divergence is not merged

GIVEN an audit record whose audit type value is security in both locations
WHEN a contributor edits the audit type to architecture
  AND the record is later changed by hand so the body section reads licence while the front-matter type remains architecture
THEN the edit writes architecture to both the Audit Type section and the front-matter type key
  AND the view after the hand edit displays licence from the body section
  AND the front-matter type key still reads architecture and is not repaired
