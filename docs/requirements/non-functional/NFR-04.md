# NFR-04 Persistence

## Description
This group records the requirement that all saved data use text files, that Papyrus not read from or write to paths outside the project directory except during `init`, and that Papyrus no longer maintain file-level interoperability with Backlog.md, offering a one-way import script instead (NFR-04.004). NFR-04.003 is superseded. Detailed boundary interpretations are noted in the atomic requirements.
