# TC-157 A record file begins with a front-matter block in canonical order and quoted timestamps

## Description
## Scenario: A record file begins with a front-matter block in canonical order and quoted timestamps

GIVEN a newly created glossary record
WHEN a contributor inspects the record file
THEN the file begins at byte zero with a YAML front-matter block delimited by three-dash lines
  AND the general keys precede any document key
  AND created_date and updated_date are quoted ISO-8601 UTC strings of the documented form
  AND the body carries no generated title line and no generated ID line
