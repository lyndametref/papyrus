# RE-009 Change audit default statuses

## Description
## Request

Change audit record approval tracking from labels to the `status` field.

### Background

Audit records currently use labels (`issued`, `approved`) to document approval, while `status` is the record lifecycle (`active`/`archived`). The code-analyzer instructions have been updated to use `status` (`issued`/`approved`) instead of labels.

### Requested change

- Add `issued` and `approved` as valid audit `status` values (in addition to or replacing lifecycle values as appropriate).
- Update `papyrus audit create` to set the initial status to `issued`.
- Update `papyrus audit status` to accept `issued`/`approved`.
- Keep `archived` for the archived lifecycle state.
- Update agent/skill instructions and documentation accordingly.

### Impact

Audit records, code-analyzer, quality-gatekeeper, security-officer, and release-management flows.
