# TC-190 A comma-separated status list is stored as a flow sequence and an empty value is refused

## Description
## Scenario: A comma-separated status list is stored as a flow sequence and an empty value is refused

GIVEN a valid configuration whose glossary entry declares active and archived
WHEN a contributor sets document_types.glossary.statuses to active,review,archived
  AND then sets the same key to an empty value
THEN the first change is stored as a flow sequence and read back as active, review, and archived in that order
  AND the empty value is refused with one validation outcome and exit code 4
  AND the stored list is unchanged by the refused change
