## Scenario: Boundary: empty assignee list imports as an empty YAML list

GIVEN a source Backlog.md task with `assignee: []`
  AND an initialized Papyrus target project
WHEN the user runs `papyrus import backlog --from <source>`
THEN the imported file contains `assignee: []`
  AND the file parses as valid YAML and `papyrus task view` reports no assignees
  AND no spurious unquoted tokens are introduced
