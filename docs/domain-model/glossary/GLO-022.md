# GLO-022 Seed

## Definition
The single built-in table of default document types; each entry lists a type's document model, role field sets, statuses, prefix, folder, and presentation facts. A configured type resolves against the seed entry of the same slug, and a user-defined slug has no seed entry.

Also known as: seed table, seed entry.

Related terms: Document Type, Document Model, GroupedMarkdown, SingleHtmlMockup.
