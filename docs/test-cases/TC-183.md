# TC-183 Record files, JSON payloads, and status codes are compared strictly

## Description
## Scenario: Record files, JSON payloads, and status codes are compared strictly

GIVEN captured baseline artifacts from the pre-refactor build
  AND a fixture corpus with at least one type per document model, a grouped type with multiple members, an HTML mockup in each metadata state, a user-defined SingleMarkdown type, a record with an unresolved reference, and a record at the archived boundary
WHEN the same create, list, view, edit, archive, delete, and status commands run against the baseline and the refactored build
THEN every record file is byte-identical
  AND every JSON payload is byte-identical, including the documented key order
  AND every HTTP status code is identical
  AND no difference is accepted by a semantic comparison
