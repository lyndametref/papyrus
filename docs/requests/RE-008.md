# RE-008 Order milestones by lowest task ordinal ascending and mark closed milestones with cleanup in browser

## Description
-
## Items

### Item 1
- Statement: In the browser Backlog view, order milestones by the lowest task ordinal they contain (ascending); order releases by the lowest task ordinal among their milestones (ascending); mark open milestones and planned releases with 🔘 before the title; mark closed milestones and released releases with ✅ before the title; add a cleanup control after the title that archives the closed milestone, or, for a released release, the closed milestones it contains.
- Requester and context: user, 2026-11-18, browser release/milestone usability.
- Theme: browser milestone and release views
- Affected area: browser rendering
- Open questions: resolved 2026-11-19; see Resolved decisions.
- References: REQ-006.020, REQ-006.021, REQ-006.022

## Grouping

- browser milestone and release views -> Item 1 -> browser rendering

## Resolved decisions

- 2026-11-19 requester: records with no tasks come last; ties sort by ID ascending.
- 2026-11-19 requester: releases follow the same ordering rule as milestones: lowest contained task ordinal, ascending.
- 2026-11-19 requester: ✅ applies to closed milestones and released releases; 🔘 applies to open milestones and planned releases; archived records stay hidden.
- 2026-11-19 requester: the release cleanup archives closed milestones inside the release; the release itself is never archived.
- 2026-11-19 requester: the milestone cleanup archives the closed milestone itself.
- 2026-11-19 requester: cleanup shows a confirmation listing affected IDs and archives nothing on cancel.

None.
