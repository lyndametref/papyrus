# REL-001 Release 1.0.0
## Description
Release 1.0.0 of the descriptor-driven document engine refactor, built from commit 38736ae.

## What was done
- One field-driven engine over the three document models.
- Seed table as the single definition of built-in types.
- Nested configuration with selector paths.
- One browser surface for every document type.
- Performance work: inventory p95 247 ms at 1,000 records on the measurement host.
- Cleanup, documentation, audits, and the single release package.
