# TC-130 A document-types entry that declares model, title, content, or id_shape is rejected

## Description
## Scenario: A document-types entry that declares model, title, content, or id_shape is rejected

GIVEN a document-type entry that declares the keys model and id_shape
WHEN a contributor runs any command in that project
THEN the command refuses to run with one validation outcome and exit code 4
  AND the diagnostic names document_types.deploy.model and document_types.deploy.id_shape
  AND the entry's model remains the seed model or SingleMarkdown for a user-defined slug
