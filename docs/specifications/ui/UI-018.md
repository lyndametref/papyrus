# UI-018 Papyrus Local Browser (Navigation without Removed Sections)

## View
browser-navigation-without-removed-sections

## Description
Ticket TASK-171; status and wording correction TASK-199. Removes Configuration, Managed artifacts and lifecycles, and Agent skills and workflows entries and routes from the browser shell navigation (REQ-06.018, RE-005, ADR-034, TECH-080, NFR-01.002). The three utility entries (Configuration, Managed artifacts and lifecycles, Agent skills and workflows) that were appended after the document-type groups are removed from the sidebar; the Backlog, Decisions, and Documents groups are unchanged. No nav entry or route remains for the three sections. Configuration editing remains via CLI (papyrus config); managed-artifact and skill documentation remains outside the browser. Underlying records and configuration files unchanged; other pages and navigation continue to work. Platforms: web only (local browser); desktop frame; responsive behavior inherited from shared shell (UI-016). Active elements: sidebar document-type links, navigation toggle, breadcrumb links, record view and edit links. States: none added; happy path only. Approval: MOCK-020 is approved, so this UI specification is status verified and describes the navigation implemented in TASK-173 and TASK-174.
