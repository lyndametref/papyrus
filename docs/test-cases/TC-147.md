# TC-147 An audit create that omits content writes no file

## Description
## Scenario: An audit create that omits content writes no file

GIVEN a project whose configuration enables the audit type
WHEN a contributor creates an audit record with a title but no content
THEN the create reports one validation outcome and exit code 4
  AND the outcome names content as missing
  AND no audit record is written
