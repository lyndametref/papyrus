# TC-070 Releases are ordered by lowest contained task ordinal ascending

## Description
## Scenario: Releases are ordered by lowest contained task ordinal ascending

GIVEN release REL-B contains a milestone with non-archived task ordinal 25
  AND release REL-C contains a milestone with non-archived task ordinal 5
WHEN a contributor opens the Backlog view
THEN the REL-C separator appears before the REL-B separator
