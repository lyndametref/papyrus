# TC-022 An archived milestone is viewable but not editable

## Description
## Scenario: An archived milestone is viewable but not editable

GIVEN an initialized Papyrus project with an archived milestone MS-008
WHEN the user runs `papyrus milestone view MS-008`
  AND the user runs `papyrus milestone edit MS-008 --title "New title"`
THEN the view shows the milestone with its stored status
  AND the edit is rejected with a validation outcome and exit code 4
  AND no file is written or moved
  AND the milestone remains archived
