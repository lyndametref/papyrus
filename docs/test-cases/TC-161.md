# TC-161 A use-case create supplies only a title and exposes the status verb

## Description
## Scenario: A use-case create supplies only a title and exposes the status verb

GIVEN a project whose configuration enables the use-case type
WHEN a contributor creates a use case titled Checkout returns with only a title
  AND requests help for the use-case command
THEN the record has the status active and a UC prefix
  AND the help offers the status verb and the description and applicability options in that order
  AND no extension verb is offered
