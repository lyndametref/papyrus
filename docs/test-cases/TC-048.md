# TC-048 Milestone edit replaces the description with multiline text supplied on standard input

## Description
## Scenario: Milestone edit replaces the description with multiline text supplied on standard input

GIVEN an existing milestone whose description is "Original milestone description"
  AND the milestone has the status "open"
  AND standard input carries a description of two lines
WHEN the user runs the milestone edit command for that milestone with the description supplied on standard input
THEN the command exits successfully
  AND viewing the milestone shows both description lines in order
  AND the milestone status remains "open"
