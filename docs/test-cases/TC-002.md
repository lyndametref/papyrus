## Scenario: Imported Backlog.md task metadata is preserved after import

GIVEN a source Backlog.md project containing a task with populated status, milestone, labels, dependencies, documentation, type, and ordinal fields
  AND an initialized Papyrus target project containing the referenced milestone and dependency tasks after import ordering
WHEN the user runs `papyrus import backlog --from <source>`
THEN `status`, `labels`, `documentation`, `type`, and `ordinal` match the source values
  AND the milestone reference is translated to the imported milestone ID (or dropped to `null` when unresolved)
  AND each dependency is translated to the imported task ID (or dropped when unresolved)
  AND `papyrus task list` shows the imported task with its title rather than the ID fallback
