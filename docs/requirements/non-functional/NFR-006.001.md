# NFR-006.001 GPL-3.0-or-later License

## Description

Papyrus shall be licensed under GPL-3.0-or-later.

## Rationale

The "or later" grant avoids a relicensing step when a new GPL version is adopted.

## Verification Method

Confirm that the repository license declaration, the build manifest license field, and the distributed copyright notice all declare GPL-3.0-or-later.
