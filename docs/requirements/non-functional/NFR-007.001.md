# NFR-007.001 Inventory Latency at 1,000 Records

## Description

The document-type inventory page (`/`) shall be served with a p95 latency below 250 ms when 1,000 active records exist across the enabled document types.

## Rationale

Keeps the inventory usable at the 1,000-record scale the engine is designed for.

## Verification Method

On reference hardware (4 vCPU, 8 GiB RAM, SSD, Linux, one server process, loopback HTTP, release build with LTO and strip), load 1,000 active records across the enabled document types, including a grouped-record group with 200 members and a formatted-record type with 50 records. Send 10 warm-up requests and 100 measured sequential requests to `/` against one running server; report the server-observed p50 and p95, excluding the first request after a cold start and any request that triggers a configuration reload. p95 shall be below 250 ms; record the run and the measured p95 with the release.
