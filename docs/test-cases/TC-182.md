# TC-182 The benchmark protocol measures 100 and 1,000 records with warm-up and recorded hardware

## Description
## Scenario: The benchmark protocol measures 100 and 1,000 records with warm-up and recorded hardware

GIVEN the MS-032 benchmark harness and its two corpus profiles of 100 and 1,000 active records
WHEN the harness runs each profile on the reference hardware with one server process, loopback HTTP, and a release build with LTO and strip
THEN each profile performs its documented warm-up requests before the measured runs
  AND the measured runs are sequential and exclude the cold-start request and configuration reloads
  AND the harness reports p50 and p95 for inventory, view, and edit
  AND the run records the exact harness commands, the corpus definition, and the hardware description
