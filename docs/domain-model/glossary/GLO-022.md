# GLO-022 Seed

## Definition
The built-in list of default record types offered at initialization. It has two families: the document-type Seed, which lists document types with their model, field sequence, prefix, folder, and reference visibility, and the decision-type Seed, which lists decision types with their prefix, folder, and the shared status vocabulary.

Also known as: seed table, seed entry, document-type seed, decision-type seed.

Related terms: Document Type, Record Type, Decision Type, Grouped Record, Formatted Record.
