## Scenario: Uniform single-record layout applies to every managed Markdown record type

GIVEN a record exists for each managed Markdown record type that has a single record view
WHEN the user opens each record's single view
THEN each view shows the record ID as small text above the title
  AND each view shows the title big and bold
  AND each view shows the status beside the ID in a label element
  AND each view shows the created and updated dates as small text under the title before references
  AND each view shows references, dependencies, and dependents as separate collapsible sections only when non-empty
  AND no view repeats the document type
  AND all metadata is shown under the artifact content
