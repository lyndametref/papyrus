Clean up all — per-milestone bulk archive

What to review

  • Placement. The action sits inside the column header of the final configured status column, directly beneath the status heading; no other column, the trailing Unconfigured status column, or the Tasks without a milestone section offers it.
  • Warning region. Server-rendered above the milestone's columns and below the milestone heading: names the milestone and status, states the count as the word warning plus a sentence, lists IDs in ascending order with titles, then the controls.
  • Empty column. The action is still present before activation; after activation the warning states that nothing will be archived and only Cancel is offered.
  • Failure report. A role="alert" region above the release groups names the archive counts and lists each failed ID with its message; the rest of the column is already archived.
  • 320 px. The action, the warning text, the ID list, and the controls stack in one column; the confirm control spans the available width.

Annotation (not part of the design): the package shows the web platform only. Selecting a current status, dragging cards, and the task record view are unchanged behaviour; their layouts stay as approved in MOCK-0002.
