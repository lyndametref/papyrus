# REQ-004.003 Inspect Decisions

## User Story

As a project contributor, I want to read decisions and find them by type so that the reasoning behind the project is available.

## Group

REQ-004 Decision Records

## Criticality

Must have

## Description

**View.** `papyrus decision view <ID>` shows a decision's identifier, title, type, status, decision text, context, consequences, date, labels, references, and, when it has been superseded, its successor. A decision that has been moved into the archive folder is not viewable: the command and the browser treat it like an unknown identifier (REQ-004.002).

**List.** `papyrus decision list` prints the decisions as plain text by default and honours the global `--json` option (REQ-001.004). It shows the identifier, title, type, status, and date of each decision, and it can be filtered by decision type. Decisions moved to the archive folder are excluded from the list.

## Acceptance Criteria

- `papyrus decision view <ID>` shows the identifier, title, type, status, decision text, context, consequences, date, labels, and references.
- A superseded decision's view names its successor.
- A decision moved to the archive folder is not viewable and produces the same outcome as an unknown identifier.
- `papyrus decision list` shows the identifier, title, type, status, and date of each decision.
- The list can be filtered by decision type.
- Archived decisions are excluded from the list.
- The list prints plain text by default and honours the global `--json` option.
