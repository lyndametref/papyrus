# TC-198 A browser save on an archived record is rejected and writes nothing

## Description
## Scenario: A browser save on an archived record is rejected and writes nothing

GIVEN a project with an archived document record opened in the browser edit form
WHEN a contributor submits the form
THEN the submission is rejected with a validation outcome
  AND the record file is unchanged
  AND the record remains archived
