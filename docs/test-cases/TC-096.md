# TC-096 Cleanup reports a failure, continues with remaining milestones, and leaves the failed milestone visible

## Description
## Scenario: Cleanup reports a failure, continues with remaining milestones, and leaves the failed milestone visible

GIVEN a cleanup confirmation lists closed milestones MS-026 and MS-027
  AND archiving MS-026 fails
WHEN a contributor confirms the cleanup
THEN the failure for MS-026 is reported
  AND MS-027 is archived
  AND MS-026 remains visible in the Backlog view
