# TC-114 config set materializes only the target entry and applies one change

## Description
## Scenario: config set materializes only the target entry and applies one change

GIVEN a project configuration whose document_types declares a glossary entry with its prefix and directory and no other keys
WHEN a contributor sets document_types.glossary.record_name to Term
THEN the glossary entry gains only the record_name key with its value
  AND no other entry and no other key is written to the configuration file
  AND the attributes the glossary entry still omits keep their model-level defaults
