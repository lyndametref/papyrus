## Scenario
An `Origin` using the `https://` scheme is normalized to the same host identity and accepted for a host in the allowed host set.

## Preconditions
- An initialized Papyrus project with at least one editable record.
- The browser server running on `127.0.0.1:<port>`.
- A valid urlencoded edit form body for that record, including its current `version` token.

## Steps
1. Render the edit form for an existing record and capture its `version` token.
2. Send `POST /doc/<record-id>` with `Host: 127.0.0.1:<port>`, `Origin: https://127.0.0.1:<port>`, `Content-Type: application/x-www-form-urlencoded`, and the valid form body.

## Expected outcome
- The POST returns `303 See Other` (not `403`).
- The edit is persisted.
