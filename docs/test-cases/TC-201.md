# TC-201 The init walkthrough writes the selected Seed entries and a non-interactive run writes every entry

## Description
## Scenario: The init walkthrough writes the selected Seed entries and a non-interactive run writes every entry

GIVEN an interactive terminal
WHEN the user completes the init walkthrough selecting one decision type and a subset of document types
THEN only the selected entries are written, each fully expanded with the prompted prefix and folder
  AND the backlog families are always written
GIVEN a run without an interactive terminal
WHEN the user runs `papyrus init NAME`
THEN every Seed entry of both families is written with the default prefixes and folders
