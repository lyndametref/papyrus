# TC-146 An audit create defaults the audit type to security

## Description
## Scenario: An audit create defaults the audit type to security

GIVEN a project whose configuration enables the audit type
WHEN a contributor creates an audit record titled Dependency check without an audit-type option
THEN the record's front-matter audit_type is security, written from the field default declared for the type
  AND no audit-type body section is written because the field is metadata-only
