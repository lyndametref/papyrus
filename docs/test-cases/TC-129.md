# TC-129 An unknown or disabled document slug is a usage error

## Description
## Scenario: An unknown or disabled document slug is a usage error

GIVEN a configuration that disables the use-case entry
WHEN a contributor invokes a document command with an unconfigured slug
  AND invokes the use-case command
THEN each invocation is a usage error with exit code 2
  AND neither invocation falls back to another command
  AND no record is read or written
