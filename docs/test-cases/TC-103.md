# TC-103 An unknown document-type key is ignored with a warning and reported by check

## Description
## Scenario: An unknown document-type key is ignored with a warning and reported by check

GIVEN a document-type entry that declares the unknown key template
WHEN a contributor runs any command in that project
  AND runs check
THEN each command runs normally and the configuration load prints one warning naming the ignored key location document_types.req.template
  AND check reports the unknown key as a finding at the same location
  AND no command is refused and no behavior changes because of the ignored key
