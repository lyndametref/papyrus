# TC-027 Collapsible sections are native details elements collapsed by default

## Description
## Scenario: Collapsible sections are native details elements collapsed by default

GIVEN a record with non-empty references, dependencies, and dependents
WHEN the user opens the record's single view
THEN each of references, dependencies, and dependents is rendered as a native HTML disclosure element
  AND each disclosure element is collapsed by default
  AND each disclosure element has a visible summary
