# TC-172 config list prints seed-filled values addressed by selector paths

## Description
## Scenario: config list prints seed-filled values addressed by selector paths

GIVEN a configuration whose req entry declares no label and no fields
WHEN a contributor runs config list
THEN the output includes the effective label and the seed fields of req
  AND each leaf is addressed by its selector path
  AND field properties are addressed with the keyed field selector form
