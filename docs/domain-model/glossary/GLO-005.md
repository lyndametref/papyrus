# GLO-005 Document Type

## Definition
A declaration of one kind of document record, identified by its slug and described by its record model, ID prefix, folder, statuses, field sets, verbs, and presentation facts. A document type is a descriptor, not a record: it has no identifier or body of its own, and every document record belongs to exactly one document type.

Also known as: document type descriptor, descriptor.

Related terms: Record Type, Document, Field Specification, Role, Seed.
